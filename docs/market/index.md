# 市场分析

中国家装行业市场规模已突破 3.2 万亿元（2025年），覆盖从一线城市到县域市场的多层次消费需求。据中国建筑装饰协会统计，行业年增长率保持在 5.8% 以上，旧房翻新占比已达 40%，智能家居渗透率突破 35%，市场正从"新房主导"向"存量改造+智能化升级"转型。

本板块基于全国 30+ 城市的市场调研数据，提供各城市家装市场的价格水平、消费趋势、主流装修模式占比等核心数据。数据覆盖一线城市（北京、上海、广州、深圳）、新一线城市（杭州、成都、武汉等12城）及其他重点城市（厦门、济南、大连等10城），帮助业主把握当地装修成本，帮助从业者洞察市场趋势。

**核心数据速览（2025-2026年）**：
- 市场规模约 **3.2 万亿元**，同比增长 5.8%
- 装修模式占比：半包 45%、全包 30%、整装 15%、其他 10%
- 人工费年均涨幅：一线城市 8-10%、新一线城市 5-7%、二三线城市 4-5%
- 消费趋势：个性化定制增长 23%、智能家居渗透率 35%、旧房翻新占比 40%

> 📊 数据来源：中国建筑装饰协会《2025中国住宅装饰装修行业发展报告》、久益一修全国 30+ 城市报价体系、各地装饰协会市场监测数据
