# 木工施工工艺流程

## 吊顶施工

### 施工流程
1. **弹线** → 确定吊顶高度和造型
2. **安装吊杆** → 间距≤100cm
3. **安装龙骨** → 主龙骨间距≤100cm，副龙骨间距≤40cm
4. **安装石膏板** → 错缝安装
5. **接缝处理** → 嵌缝石膏+绷带
6. **防锈处理** → 钉眼点防锈漆

### 工艺要点
- 转角处用整板切割
- 石膏板与墙面留缝 3-5mm
- 重型灯具单独吊挂
- 厨卫用铝扣板吊顶

## 柜体制作

### 施工流程
1. **放线** → 确定柜体位置
2. **制作框架** → 板材切割组装
3. **安装背板** → 固定在墙面上
4. **安装门板** → 调整缝隙
5. **安装五金** → 铰链、滑轨

### 工艺要点
- 板材切割精确
- 封边严密
- 铰链间距≤60cm
- 门板缝隙均匀

## 验收要点

- [ ] 吊顶平整度≤3mm/2m
- [ ] 石膏板接缝错开
- [ ] 转角整板切割
- [ ] 柜体牢固
- [ ] 门板开合顺畅
- [ ] 五金安装齐全

## 施工工艺详解

### 弹线与标高控制
- **标高确定**：根据设计要求（通常吊顶下沿距地面 2.4-2.6m），用激光水平仪在四周墙面弹出水平线，误差≤2mm
- **造型定位**：如有叠级造型或灯槽，在地面弹出吊顶造型投影线，确定龙骨走向
- **管线标注**：在天花板上标注水电管线位置，避免打钉时损坏管线

### 吊杆与龙骨安装
- **吊杆选型**：使用 φ8mm 国标全丝吊杆，膨胀螺栓固定于楼板。吊杆间距≤100cm，距主龙骨端部≤30cm
- **龙骨选型**：轻钢龙骨 50 系列（主龙骨 50×15×1.2mm，副龙骨 50×20×0.5mm），间距主龙骨≤100cm、副龙骨≤40cm
- **调平起拱**：龙骨安装后调平，中间按房间短向跨度的 1/200-3/200 起拱（如跨度 4m，起拱 20-30mm），防止吊顶下沉后出现下垂感
- **特殊处理**：吊杆长度>1.5m 时设反向支撑；吊顶内有设备（新风主机、中央空调室内机）时需加固龙骨

### 石膏板安装
- **板材选择**：常规区域用 9.5mm 纸面石膏板（龙牌、可耐福），厨卫区域用 12mm 防水石膏板（绿色面层）
- **铺设方向**：石膏板长边沿纵向次龙骨方向铺设，短边接缝必须错开≥300mm
- **固定方式**：自攻螺丝从板中心向四周固定，螺丝间距：板边 150-170mm，板中 200mm，钉头嵌入板面 0.5-1mm
- **边缘处理**：石膏板与墙面留缝 3-5mm（防止热胀冷缩导致开裂）

### 接缝处理（关键防裂工序）
1. 板缝清理，去除浮灰
2. 板缝内填充嵌缝石膏（美巢 400，约 25 元/20kg）
3. 贴接缝纸带（或自粘网格布），用刮刀刮平，赶走气泡
4. 干燥后（约 24 小时）打磨平整
5. 满刮腻子 2-3 遍，每遍干透后再刮下一遍

### 铝扣板吊顶（厨卫专用）
- **基层处理**：安装边角收边条，用膨胀螺丝固定于墙面
- **龙骨安装**：三角龙骨间距≤60cm，与铝扣板短边方向平行
- **板安装**：从一角开始逐块扣入，注意板面方向一致
- **开孔处理**：灯具、排风扇位置用专用开孔器开孔，边缘用收边条处理

## 施工不合格案例

### 案例一：吊顶龙骨未起拱
某客厅跨度 5m，施工方安装龙骨时未做中间起拱处理，石膏板安装后出现中间下垂现象（约 8mm 下垂量）。整改：拆除石膏板，重新调平龙骨并设置 25mm 起拱量，重新安装石膏板，费用约 1200 元。

### 案例二：柜体门板缝隙不均
定制衣柜安装后，两扇对开门缝隙上宽下窄（上 5mm、下 1mm）。经查明是柜体安装时未找垂直，倾斜了约 3mm。整改：松开柜体固定螺丝，用水平仪重新调垂直后固定，再调整铰链使缝隙均匀至 2-3mm。

## 注意事项
- 木工进场前，水电管线必须验收合格并完成拍照存档
- 石膏板运输和存放应平整放置，避免受潮变形
- 施工环境温度 5-35℃，湿度不超过 85%
- 厨卫吊顶优先选用铝扣板，如选防水石膏板，必须配套防水漆
- 现场制作柜体不如工厂定制柜精度高，建议选择全屋定制
