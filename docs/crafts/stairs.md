- 照明充足

## 施工要点详解

### 尺寸计算
- **踏步计算公式**：2×踏步高度 + 踏步宽度 ≈ 60-62cm（人体工程学舒适步幅）
- **踏步高度**：家用推荐 16-17.5cm，过陡（>18cm）行走疲劳，过缓（<15cm）踏步数过多
- **踏步宽度**：推荐 26-30cm，确保脚掌能完全落在踏面上
- **楼梯宽度**：单人通行≥90cm，双人通行≥120cm
- **扶手高度**：从踏步前沿垂直量至扶手顶面，≥90cm；儿童使用可增设 60cm 高度的辅助扶手

### 实木楼梯施工
- **施工流程**：测量放线 → 安装龙骨（钢架或混凝土基层） → 安装踏步板 → 安装立板 → 安装扶手和栏杆 → 表面处理
- **工艺要点**：踏步板与龙骨之间需加减震垫以减少噪音；扶手接头采用 45° 斜接；栏杆立柱间距≤11cm
- **材料选择**：踏步板推荐橡木、白蜡木或榉木，厚度≥25mm，硬度高、耐磨性好
- **表面处理**：水性木器漆 3 遍（底漆 1 遍 + 面漆 2 遍），或木蜡油 2 遍

### 钢结构楼梯施工
- **施工流程**：测量放线 → 焊接钢骨架 → 防腐处理 → 安装踏步 → 安装扶手
- **工艺要点**：钢骨架焊接后打磨焊缝，涂刷防锈漆 2 遍；踏步下方加隔音棉降低行走噪音
- **注意事项**：钢结构楼梯需考虑承重设计，单层住宅活荷载取 2.0kN/㎡

### 安全细节
- **栏杆间距**：垂直栏杆间距≤11cm（防止儿童头部卡入）
- **踏步防滑**：踏步前沿做防滑条或开防滑槽，有老人和儿童的家庭建议满铺防滑垫
- **照明**：楼梯间需设置双控开关（楼上楼下均可控制），踏步下方可嵌入 LED 灯带作为夜间照明
- **扶手固定**：扶手膨胀螺栓间距≤1m，末端需固定防止松动

## 施工不合格案例

### 案例一：楼梯踏步高度不一
某复式楼装修后，业主发现楼梯最后一级踏步高度比其余踏步高出 3cm。经查是地面找平后标高变化导致。整改：重新调整最后一级踏步的基层高度，使所有踏步高度一致（允许偏差≤5mm）。踏步高度不一致极易导致踩空摔倒，存在严重安全隐患。

### 案例二：实木踏步开裂
入住一年后实木楼梯踏步板出现多处开裂。经查明，使用的木材含水率偏高（出厂含水率 18%，而使用地平衡含水率为 12%），干燥后收缩开裂。整改：更换踏步板，选用含水率与当地平衡含水率接近的木材（一般 8-12%），费用约 3000 元。

## 注意事项
- 楼梯施工前需复核结构标高，确保踏步高度均匀一致
- 有老人和儿童的家庭不建议使用旋转楼梯，踏步宽度变化容易踩空
- 楼梯踏步数量最好是奇数（心理学上感觉更舒适）
- 楼梯下方空间可设计为储物柜或书架，提高空间利用率
