# 全屋净水系统

## 系统组成

| 设备 | 位置 | 作用 | 价格 |
|------|------|------|------|
| 前置过滤器 | 入户总管 | 过滤大颗粒杂质 | 200-800 |
| 中央净水机 | 总管 | 去除余氯、有机物 | 2000-6000 |
| 中央软水机 | 总管 | 软化水质 | 3000-8000 |
| 末端净水机 | 厨房 | 直饮水 | 1000-5000 |
| 管线机 | 厨房 | 即热饮水 | 1000-3000 |

## 选择建议

### 基本配置
- 前置过滤器 + 末端净水机

### 完整配置
- 前置 + 中央净水 + 中央软水 + 末端净水

## 安装要点

- 预留安装空间
- 预留电源
- 预留排水口
- 在水电阶段确定位置

## 维护

| 设备 | 维护周期 | 维护内容 |
|------|---------|---------|
| 前置过滤器 | 每月 | 冲洗 |
| 中央净水 | 每年 | 更换滤芯 |
| 中央软水 | 每月 | 加盐 |
| 末端净水 | 每半年 | 更换滤芯 |

## 各设备详解

### 前置过滤器
- **过滤精度**：40μm，可过滤泥沙、铁锈等大颗粒杂质
- **安装位置**：入户水表之后、总阀之前，便于维护时不影响其他用水
- **安装要求**：预留 20-30cm 的安装空间，底部留排水口用于反冲洗
- **推荐型号**：霍尼韦尔 F06（约 500 元）、BKA S3W（约 400 元）、沁园 QJ-UF-01D（约 300 元）
- **注意事项**：北方水质较硬的地区建议选带反冲洗功能的型号，减少手动维护频率

### 中央净水机
- **核心滤料**：活性炭 + KDF（铜锌合金），可去除余氯、有机物、部分重金属
- **处理流量**：1-2T/h（根据户型选择，100㎡ 以下选 1T/h，100-150㎡ 选 1.5T/h）
- **安装位置**：前置过滤器之后，需预留排水口用于反冲洗
- **推荐型号**：滨特尔 ECF-10（约 3500 元）、怡口 ERF-301（约 4500 元）
- **注意事项**：中央净水机出水不建议直接饮用，需配合末端净水机使用

### 中央软水机
- **工作原理**：离子交换树脂去除水中的钙镁离子，降低水硬度
- **适用场景**：水质硬度较高的地区（硬度>170mg/L），可保护热水器、地暖管道等设备
- **安装要求**：需预留电源（控制器用电）、排水口（再生排水）、盐箱加盐空间
- **盐耗量**：每月约 5-10kg 软水盐（视用水量和水质硬度而定）
- **推荐型号**：滨特尔 SFT-20（约 5000 元）、怡口 ESR-20（约 6000 元）
- **注意事项**：软水不适合长期饮用（钠含量偏高），建议软水和饮用水分路供应

### 末端净水机（RO 反渗透）
- **过滤精度**：0.0001μm，可去除细菌、病毒、重金属等，出水可直接饮用
- **核心滤芯**：PP 棉 + 活性炭 + RO 膜 + 后置活性炭（四级或五级过滤）
- **安装位置**：厨房水槽下方，需预留电源和排水口（RO 机有废水排出）
- **废水比**：推荐选择废水比 2:1 或 3:1 的型号（产水 2-3 升排废水 1 升）
- **推荐型号**：小米 600G（约 1200 元）、沁园 QR-RU-05D（约 2500 元）、AO 史密斯 AR1000（约 3500 元）
- **注意事项**：RO 滤芯寿命一般 2-3 年，年更换成本约 300-600 元

### 管线机
- **功能**：即热式饮水，可实现多档温度调节（常温/温水/开水）
- **安装方式**：壁挂安装，通过 PE 管与末端净水机连接
- **安装要求**：需预留电源，与末端净水机距离不超过 3m
- **推荐型号**：管线机 + 净水机组合套装约 1500-3000 元

## 安装不合格案例

### 案例一：软水机排水管未接入地漏
某业主安装软水机后，再生排水直接排入下水道但未密封，导致异味返入室内。整改：将排水管接入专用地漏并用防臭接头密封，同时安装止回阀防止回流。

### 案例二：末端净水机废水管未装止回阀
RO 净水机废水管直接插入下水道，停水时下水道污水倒灌进入废水管。整改：废水管安装止回阀，并采用间接排水方式（管口距排水口保持 5cm 以上的空气隔断）。

## 注意事项
- 全屋净水系统需在水电阶段确定方案，预留好设备位置和上下水接口
- 北方寒冷地区，安装在阳台或车库的设备需做防冻处理
- 购买时关注滤芯更换成本，部分机器售价低但滤芯价格高
- 不建议仅靠 TDS 笔判断水质，TDS 只能反映水中溶解性固体总量
