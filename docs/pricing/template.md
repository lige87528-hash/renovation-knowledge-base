## 注意事项

1. 所有材料必须注明品牌、型号、规格
2. 单价包含人工和材料
3. 工程量以实际测量为准
4. 增项不得超过总价的 5%

## 报价审核要点

收到装修公司报价后，重点检查以下"猫腻"：

### 常见漏项
- 垃圾清运费（通常 500-2000 元）
- 材料搬运费（无电梯楼层加收）
- 成品保护费（门套、窗台、地暖保护）
- 水电开槽费（部分公司单列）
- 防水面积（卫生间墙面防水高度 1.8m，地面全做）
- 包立管（每根 100-200 元）
- 门槛石/窗台石（通常不包含在主报价中）

### 数量虚报识别
- 墙面面积 = 地面面积 × 2.5（粗略估算）
- 电线用量 = 地面面积 × 3-4 米/㎡
- 水管用量 = 按实际走向测量
- 瓷砖用量 = 铺贴面积 + 5-10% 损耗

### 单价合理性判断
- 水电改造：明管 30-40 元/m，暗管 50-70 元/m
- 贴砖：常规规格 35-50 元/㎡，大砖或斜铺加价 30-50%
- 墙面：腻子+乳胶漆 25-40 元/㎡
- 防水：50-80 元/㎡

## 报价计算工具

**半包总价快速估算公式：**
```
总价 = 建筑面积 × 每平米单价
例：100㎡ × 800元/㎡ = 8万元（中档半包）
```

**全包总价快速估算公式：**
```
总价 = 建筑面积 × 每平米单价
例：100㎡ × 1500元/㎡ = 15万元（中档全包）
```
