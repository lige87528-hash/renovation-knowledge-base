# 装修面积计算指南

## 面积类型

### 建筑面积
- 房产证上的面积
- 包含公摊面积

### 套内面积
- 实际使用面积
- 装修报价通常按此面积

### 装修面积
- 各房间实际面积之和
- 装修报价的实际依据

## 各空间面积计算

### 地面面积
```
地面面积 = 长 × 宽
```

### 墙面面积
```
墙面面积 = (房间周长 × 层高) - 门窗面积
```

### 顶面面积
```
顶面面积 = 地面面积
```

## 注意事项

1. 报价面积以实际测量为准
2. 公摊面积不应计入装修报价
3. 墙面面积系数约为地面面积的 2.5-3 倍
4. 复杂造型需单独计算

## 面积计算实例

### 客厅（5m × 4m，层高 2.8m）
- 地面面积：5 × 4 = 20㎡
- 墙面面积：(5 + 4) × 2 × 2.8 - 门窗面积（约 5㎡）= 45.4㎡
- 顶面面积：20㎡

### 卧室（3.5m × 3m，层高 2.8m）
- 地面面积：3.5 × 3 = 10.5㎡
- 墙面面积：(3.5 + 3) × 2 × 2.8 - 门窗面积（约 3㎡）= 33.4㎡
- 顶面面积：10.5㎡

## 常见面积争议

### 争议一：按建筑面积还是套内面积报价？
**行业惯例**：半包按套内面积或装修面积报价，全包可能按建筑面积报价。
**建议**：明确要求按套内面积报价，更透明公平。

### 争议二：墙面面积如何计算？
**行业惯例**：有的按实际测量，有的按地面面积 × 2.5 估算。
**建议**：要求按实际测量，避免估算误差。

### 争议三：阳台面积怎么算？
**行业惯例**：封闭阳台按全面积，未封闭阳台按 1/2 面积。
**建议**：在合同中明确阳台面积计算方式。

## 面积测量工具

- **激光测距仪**：精确到毫米，推荐博世、徕卡品牌（200-500 元）
- **卷尺**：传统可靠，5m 或 7.5m 规格（10-30 元）
- **手机 APP**：部分手机自带测距功能（精度有限，仅供参考）
