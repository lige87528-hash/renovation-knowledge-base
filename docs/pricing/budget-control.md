# 装修预算控制详解

## 预算制定

### 步骤
1. 确定总预算
2. 按项目分解预算
3. 按城市市场价调整
4. 预留10-15%应急

### 预算比例
| 项目 | 占比 |
|------|------|
| 设计费 | 3-5% |
| 施工费 | 25-30% |
| 主材费 | 30-35% |
| 家具费 | 15-20% |
| 家电费 | 10-15% |
| 软装费 | 5-10% |

## 预算控制

### 事前控制
- 做好预算计划
- 明确各项支出
- 设定上限

### 事中控制
- 实时记录支出
- 对比预算和实际
- 及时调整

### 事后控制
- 结算核对
- 分析超支原因
- 总结经验

## 超支原因

| 原因 | 处理方法 |
|------|---------|
| 设计变更 | 减少变更 |
| 材料升级 | 控制升级 |
| 增项 | 约定上限 |
| 返工 | 严格验收 |

## 省钱技巧

- 淡季装修
- 集中采购
- 关注促销
- 自己采购主材
- 减少造型
- 选择国产品牌

## 预算控制实战案例

### 案例：100㎡ 舒适型装修，预算 20 万

**初始预算分配**：
| 项目 | 预算 | 实际 | 差额 |
|------|------|------|------|
| 施工（半包） | 7万 | 7.2万 | +0.2万 |
| 主材 | 6万 | 6.5万 | +0.5万 |
| 家具 | 3万 | 2.8万 | -0.2万 |
| 家电 | 2.5万 | 2.5万 | 0 |
| 软装 | 1万 | 0.8万 | -0.2万 |
| 应急 | 0.5万 | 0.2万 | -0.3万 |
| **总计** | **20万** | **20万** | **0** |

**超支应对**：主材超支 0.5 万，通过减少软装支出（从 1 万降到 0.8 万）和家具选择性价比款（从 3 万降到 2.8 万）来平衡。

## 预算控制工具推荐

### 记账工具
- **Excel 表格**：最灵活，自定义列（项目、预算、实际、差额、备注）
- **装修 APP**：土巴兔、齐家网等 APP 内置预算跟踪功能
- **记账软件**：随手记、挖财等，创建装修专属账本

## 预算超支预警机制

设置三级预警：
- **黄色预警**：单项超支 5-10% → 关注，从其他项目调减
- **橙色预警**：单项超支 10-20% → 调整后续预算计划
- **红色预警**：总预算超支 10% 以上 → 暂停非必要支出，重新规划

## 装修省钱优先级（资金紧张时）

可以削减（按优先级从低到高）：
1. 装饰性项目（背景墙、复杂吊顶）
2. 软装（后期逐步添置）
3. 非核心区域材料标准
4. 家具品牌

不可削减：
1. 水电工程
2. 防水材料
3. 环保指标
4. 五金配件
