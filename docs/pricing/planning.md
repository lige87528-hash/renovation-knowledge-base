# 装修预算规划详解

## 预算制定步骤

### 第一步：确定总预算
根据经济状况确定可承受的总金额。

### 第二步：分解预算
| 项目 | 占比 | 金额 |
|------|------|------|
| 设计费 | 3-5% | |
| 施工费 | 25-30% | |
| 主材费 | 30-35% | |
| 家具费 | 15-20% | |
| 家电费 | 10-15% | |
| 软装费 | 5-10% | |

### 第三步：市场调研
了解当地市场价，调整预算。

### 第四步：预留应急
预留10-15%的应急预算。

## 预算计算工具

### 简易预算计算器

以建筑面积为基准，快速估算装修总预算：

| 模式 | 经济型 | 舒适型 | 高端型 |
|------|-------|-------|-------|
| 半包 | 500-700元/㎡ | 700-1000元/㎡ | 1000-1500元/㎡ |
| 全包 | 800-1200元/㎡ | 1200-1800元/㎡ | 1800-2500元/㎡ |
| 整装 | 1500-2500元/㎡ | 2500-3500元/㎡ | 3500-5000元/㎡ |

### 100㎡ 装修预算速算

**半包舒适型**：
- 施工费：100㎡ × 800 = 8 万
- 主材费：约 8-10 万
- 家具家电：约 5-8 万
- 总计：约 21-26 万

**全包舒适型**：
- 总价：100㎡ × 1500 = 15 万（施工+主材）
- 家具家电：约 5-8 万
- 总计：约 20-23 万

## 预算调整策略

### 资金紧张时的优先削减顺序
1. **软装** — 后期逐步添置，不影响居住
2. **装饰性项目** — 背景墙、复杂吊顶可简化
3. **家具** — 选择性价比款，后期可升级
4. **主材** — 在不影响环保和安全的前提下适度降低
5. **施工** — 不建议削减，质量是根本

### 绝对不能省的领域
- **水电工程**：埋在地下的，返工代价极大
- **防水材料**：卫生间防水做不好，后患无穷
- **环保材料**：甲醛超标影响健康
- **五金配件**：使用频率高，劣质五金体验极差

## 预算分配示例

以 100㎡ 舒适型装修、总预算 25 万为例：

| 项目 | 预算 | 占比 | 具体分配 |
|------|------|------|---------|
| 施工（半包） | 8万 | 32% | 水电2万+泥瓦2万+木瓦1.5万+油漆1.5万+其他1万 |
| 主材 | 7万 | 28% | 瓷砖1万+地板1万+门0.6万+橱柜1.2万+卫浴1万+涂料0.3万+其他1.9万 |
| 家具 | 4万 | 16% | 客厅1.5万+卧室1.5万+餐厅0.5万+其他0.5万 |
| 家电 | 3.5万 | 14% | 空调0.8万+冰箱0.5万+洗衣机0.3万+厨房1万+其他0.9万 |
| 软装 | 1万 | 4% | 窗帘0.3万+灯具0.3万+装饰0.4万 |
| 应急 | 1.5万 | 6% | 预留备用 |
