# 设计阶段避坑详解

## 设计图纸审查

### 重点检查
1. **尺寸是否准确** → 亲自复尺
2. **功能是否合理** → 动线是否流畅
3. **材料是否标注** → 品牌型号是否明确
4. **水电点位** → 数量是否够用
5. **收纳空间** → 是否充足

### 常见设计问题

| 问题 | 后果 | 应对 |
|------|------|------|
| 尺寸错误 | 家具放不下 | 复尺确认 |
| 插座不够 | 后期拉线 | 预留充足 |
| 收纳不足 | 后期杂乱 | 提前规划 |
| 光线不足 | 居住不舒适 | 增加照明 |

## 效果图陷阱

### 效果图的猫腻
- 广角镜头让空间显大
- 灯光效果过于理想
- 家具尺寸比例失真

### 应对方法
- 要求看平面图和施工图
- 确认效果图中的材料可购买
- 要求设计师说明施工可行性

## 设计费

### 收费标准
| 级别 | 价格（元/㎡） | 内容 |
|------|-------------|------|
| 普通设计师 | 50-100 | 基础设计 |
| 主任设计师 | 100-200 | 深化设计 |
| 设计总监 | 200-500 | 全案设计 |

### 是否值得花设计费
- 预算充足：建议请独立设计师
- 预算有限：装修公司免费设计也可用

## 设计合同要点

签订设计合同时应注意：

### 设计成果交付物
- 平面布置图（含尺寸标注）
- 立面图（每面墙）
- 水电施工图
- 天花布置图
- 效果图（每个空间至少 2 张）
- 材料清单（品牌、型号、颜色）
- 家具尺寸清单

### 设计修改约定
- 方案阶段可修改 2-3 次
- 施工图确认后修改需额外收费
- 修改内容需书面确认

## 插座规划清单

每个空间建议的插座数量和位置：

| 空间 | 插座数量 | 位置 |
|------|---------|------|
| 客厅 | 8-10个 | 电视墙3-4个、沙发两侧2个、空调1个、其他2-3个 |
| 卧室 | 6-8个 | 床头两侧各2个、电视墙1-2个、空调1个、书桌2个 |
| 厨房 | 8-10个 | 台面上方4-5个（电饭煲、微波炉等）、冰箱1个、油烟机1个、水槽下2个 |
| 卫生间 | 3-4个 | 洗手台旁2个（吹风机、电动牙刷）、热水器1个、智能马桶1个 |
| 餐厅 | 2-3个 | 餐桌旁1个（火锅）、餐边柜2个 |
| 阳台 | 2-3个 | 洗衣机1个、热水器1个、备用1个 |

## 设计常见遗憾及补救

| 遗憾 | 原因 | 补救方法 |
|------|------|---------|
| 插座不够 | 前期规划不足 | 使用明线线槽或无线方案 |
| 收纳不足 | 低估物品数量 | 后期添置成品柜、墙面搁板 |
| 灯光太暗 | 灯具功率不足 | 增加台灯、落地灯辅助照明 |
| 动线不畅 | 布局不合理 | 重新调整家具位置 |
| 颜色不协调 | 缺乏整体规划 | 通过软装（窗帘、抱枕、装饰画）调和 |
