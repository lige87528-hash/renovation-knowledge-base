# 装修避坑指南

## 十大避坑要点

### 1. 选择装修公司
- 看资质
- 看工地
- 看口碑

### 2. 签订合同
- 报价单明细
- 约定增项上限
- 约定质保期

### 3. 付款
- 按进度付款
- 保留质保金
- 不要提前付款

### 4. 材料
- 进场验收
- 核对品牌型号
- 拍照留证

### 5. 施工
- 定期到工地
- 做好验收
- 做好记录

### 6. 验收
- 每个阶段验收
- 不合格不付款
- 问题限期整改

### 7. 增项
- 先确认后施工
- 约定上限
- 书面确认

### 8. 合同
- 不要签空白合同
- 保留合同原件
- 所有约定写入合同

### 9. 售后
- 确认质保期
- 保留质保合同
- 发现问题及时联系

### 10. 纠纷
- 协商解决
- 请第三方调解
- 必要时法律途径

## 装修全流程避坑时间线

### 装修前（签约前 1-2 个月）
- [ ] 确定总预算和分配比例
- [ ] 确定装修风格和功能需求
- [ ] 选择装修模式（清包/半包/全包/整装）
- [ ] 对比 3 家以上装修公司
- [ ] 实地考察在建工地
- [ ] 审核报价单，排查漏项和虚报
- [ ] 签订书面合同，明确所有条款

### 施工中（60-90 天）
- [ ] 材料进场逐项验收
- [ ] 水电完工后打压测试和绝缘测试
- [ ] 防水完工后做 48 小时闭水试验
- [ ] 每阶段验收合格后再付款
- [ ] 隐蔽工程拍照存档
- [ ] 所有变更书面确认

### 装修后（1-2 个月）
- [ ] 竣工验收逐项检查
- [ ] 室内空气质量检测
- [ ] 收集所有资料（水电图、质保卡、付款凭证）
- [ ] 确认质保期限和售后联系方式
- [ ] 通风 3-6 个月后入住

## 装修避坑核心原则

1. **先学后装**：花 1-2 周时间学习装修基础知识
2. **货比三家**：至少对比 3 家报价
3. **白纸黑字**：所有约定写入合同
4. **按步验收**：不合格不付款
5. **保留证据**：拍照、记录、保存凭证
6. **理性消费**：不被低价诱惑，不被销售催促
7. **预留应急**：预算预留 10-15% 应急
