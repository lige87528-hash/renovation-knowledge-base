# 装修避坑检查清单

## 选择装修公司
- [ ] 查看资质证书
- [ ] 实地考察
- [ ] 对比3家以上报价
- [ ] 看正在施工的工地
- [ ] 看已完工的工地

## 签订合同
- [ ] 报价单明细到每个项目
- [ ] 约定工期
- [ ] 约定付款比例
- [ ] 约定增项上限
- [ ] 约定质保期

## 施工过程
- [ ] 材料进场验收
- [ ] 每阶段验收
- [ ] 拍照记录管线
- [ ] 保留证据
- [ ] 及时沟通

## 竣工验收
- [ ] 所有功能正常
- [ ] 环保检测达标
- [ ] 资料交接
- [ ] 质保合同

## 验收补充清单

### 水电验收要点
- [ ] 水管打压测试（0.8MPa 保压 30 分钟，压降≤0.05MPa）
- [ ] 电路绝缘电阻测试（≥0.5MΩ）
- [ ] 每个插座通电测试
- [ ] 冷热水管间距≥15cm
- [ ] 强弱电间距≥30cm

### 泥瓦验收要点
- [ ] 瓷砖空鼓率≤5%（单块≤15%）
- [ ] 平整度用 2m 靠尺检测，误差≤3mm
- [ ] 卫生间坡度正确，排水通畅
- [ ] 闭水试验 48 小时无渗漏

### 油漆验收要点
- [ ] 墙面平整，无裂纹、起泡、流坠
- [ ] 阴阳角方正，误差≤3mm
- [ ] 颜色均匀，无色差

### 安装验收要点
- [ ] 门开合顺畅，密封良好
- [ ] 橱柜水平，五金正常
- [ ] 灯具安装牢固，开关正常
- [ ] 洁具安装牢固，无渗漏

## 维权证据收集

- 所有沟通尽量文字化，保留微信聊天记录
- 每个施工阶段拍照存档
- 保留所有材料包装和标签
- 保留付款凭证和合同原件
- 发现问题及时书面通知施工方并留存送达证据
