# 装修监理详解

## 监理类型

| 类型 | 价格 | 特点 |
|------|------|------|
| 装修公司监理 | 免费/含管理费 | 偏向装修公司 |
| 第三方监理 | 50-100元/㎡ | 独立公正 |
| 独立监理师 | 100-200元/㎡ | 专业但贵 |

## 工作内容

### 材料验收
- 核对品牌型号
- 检查质量

### 施工监督
- 工艺是否符合规范
- 进度是否按计划

### 验收
- 各阶段验收
- 发现问题及时整改

### 沟通
- 与施工方沟通
- 定期向业主汇报

## 验收节点

1. 拆改验收
2. 水电验收
3. 防水验收
4. 泥瓦验收
5. 木作验收
6. 油漆验收
7. 安装验收
8. 竣工验收

## 选择要点

- 有资质证书
- 有行业经验
- 独立于装修公司
- 有详细验收报告

## 各阶段验收标准详解

### 水电验收
- **水路**：打压测试 0.8MPa，保压 30 分钟，压降 ≤ 0.05MPa
- **电路**：绝缘电阻 ≥ 0.5MΩ，每个插座通电测试
- **管线间距**：冷热水管间距 ≥ 15cm，强弱电间距 ≥ 30cm
- **管线固定**：管卡间距 ≤ 60cm，转角处增设管卡
- **管线走向**：横平竖直，电上水下

### 防水验收
- **闭水试验**：蓄水 3-5cm，持续 48 小时
- **检查方法**：到楼下查看天花板是否有渗漏
- **防水高度**：淋浴区 1.8m，其他区域 30cm
- **地面坡度**：坡向地漏，排水通畅无积水

### 泥瓦验收
- **空鼓检查**：用空鼓锤敲击，空鼓率 ≤ 5%（单块 ≤ 15%）
- **平整度**：2m 靠尺检测，误差 ≤ 3mm
- **垂直度**：误差 ≤ 3mm/2m
- **阴阳角**：方正，误差 ≤ 3mm
- **缝隙**：瓷砖缝隙均匀，填缝饱满

### 油漆验收
- **平整度**：侧光检查，无明显波浪纹
- **颜色**：均匀一致，无色差
- **缺陷**：无裂纹、起泡、流坠、漏刷
- **阴阳角**：方正笔直

## 是否需要请监理？

**建议请监理的情况**：
- 全包/整装模式（需要监督施工方材料和质量）
- 业主工作忙，无法经常到工地
- 缺乏装修经验，不懂验收标准
- 装修总价较高（20 万以上）

**可以不请监理的情况**：
- 清包模式（自己采购所有材料，质量可控）
- 有装修经验或相关专业背景
- 时间充裕，能经常到工地
- 装修简单，项目少
