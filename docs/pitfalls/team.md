# 装修施工队选择

## 施工队类型

| 类型 | 特点 | 价格 |
|------|------|------|
| 散工 | 最便宜 | 300-400元/㎡ |
| 施工队 | 有一定组织 | 400-500元/㎡ |
| 装修公司 | 有保障 | 600-1000元/㎡ |

## 选择标准

### 看经验
- 从业年限
- 做过的项目
- 手艺水平

### 看口碑
- 业主评价
- 邻居推荐
- 网上评价

### 看管理
- 是否有工长
- 是否有监理
- 是否有售后

## 合作要点

- 签订书面合同
- 明确付款方式
- 约定工期
- 约定质量标准
- 约定售后

## 风险防范

- 不要一次性付款
- 保留质保金
- 做好各阶段验收
- 保留证据

## 如何找到靠谱的施工队

### 推荐渠道
- **熟人介绍**：最可靠的渠道，看过实际施工质量
- **正在装修的邻居**：到同小区正在装修的户里实地考察
- **建材市场老板推荐**：他们接触大量施工队，了解口碑
- **装修平台**：土巴兔、齐家网等第三方平台（有平台监管）

### 面试施工队长的关键问题
1. "你们一般同时做几个工地？" — 超过 3 个说明管理精力分散
2. "水电怎么走线？" — 规范答案应该是"横平竖直，走顶不走地"
3. "防水做多高？" — 卫生间墙面应做 1.8m 高
4. "瓷砖怎么验收？" — 应提到空鼓率检查和平整度检测
5. "出了质量问题怎么处理？" — 靠谱的队长会承诺免费返工

## 施工合同要点

即使找散工或施工队，也要签订书面协议：

| 条款 | 内容 |
|------|------|
| 工程范围 | 具体做哪些项目 |
| 材料供应 | 谁买什么材料 |
| 工期 | 开工和竣工日期 |
| 付款方式 | 按进度分期支付 |
| 质量标准 | 参照的国家标准 |
| 售后 | 质保期限和范围 |
| 违约 | 延期和质量问题的处理 |

## 散工 vs 施工队 vs 装修公司

| 对比项 | 散工 | 施工队 | 装修公司 |
|-------|------|-------|---------|
| 价格 | 最低 | 中等 | 最高 |
| 质量稳定性 | 低 | 中 | 高 |
| 售后保障 | 无 | 有限 | 有保障 |
| 管理省心度 | 需全程管理 | 工长协调 | 项目经理负责 |
| 适合人群 | 有经验业主 | 半包业主 | 全包/整装业主 |
