# 物业装修规定

## 装修审批流程

1. 向物业提交装修申请
2. 提供装修方案和施工图纸
3. 物业审批
4. 签订装修管理协议
5. 缴纳装修押金
6. 领取施工许可证

## 常见物业规定

### 施工时间
- 工作日：8:00-12:00, 14:00-18:00
- 周末：禁止施工或限制噪音施工
- 法定节假日：禁止施工

### 垃圾清运
- 建筑垃圾堆放指定位置
- 物业代为清运需交费
- 禁止随意丢弃

### 电梯使用
- 大型材料走货梯
- 做好电梯保护
- 避免损坏电梯

### 公共区域
- 做好走廊、电梯保护
- 不得占用公共空间
- 损坏需赔偿

## 装修押金

- 一般 1000-5000 元
- 装修完毕验收后退还
- 损坏公共区域需扣款

## 注意事项

- 提前了解物业规定
- 与物业保持良好沟通
- 遵守施工时间
- 做好成品保护

## 常见物业纠纷及处理

### 纠纷一：装修押金不退
**原因**：物业以各种理由扣留押金
**处理**：
1. 要求物业出具书面扣款说明和依据
2. 核对装修管理协议中的扣款条款
3. 如无合理依据，向住建局物业科投诉
4. 必要时通过法律途径维权

### 纠纷二：施工时间争议
**原因**：物业规定与业主需求冲突
**处理**：
1. 提前与物业协商，特殊工序可申请适当延长
2. 高噪音工序严格按物业规定时间执行
3. 书面记录协商结果

### 纠纷三：材料运输限制
**原因**：物业限制大型材料使用电梯
**处理**：
1. 提前了解电梯尺寸限制
2. 超大材料选择非高峰时段运输
3. 做好电梯保护措施

## 物业装修审批材料清单

- 装修申请表（物业提供）
- 房屋产权证或购房合同复印件
- 业主身份证复印件
- 装修方案/施工图纸
- 施工单位营业执照和资质证书复印件
- 施工人员身份证复印件

## 与物业打交道的建议

- 装修前主动拜访物业，了解所有规定和流程
- 与物业管理人员建立良好关系
- 遵守规定，不给物业添麻烦
- 遇到问题以协商为主，避免正面冲突
- 保留所有与物业的书面沟通记录
