# 装修噪音管理

## 施工噪音标准

| 时间段 | 噪音限值 |
|--------|---------|
| 白天（6:00-22:00） | ≤70dB |
| 夜间（22:00-6:00） | ≤55dB |

## 噪音来源

| 工序 | 噪音等级 |
|------|---------|
| 拆墙 | 80-100dB |
| 电锤开槽 | 90-110dB |
| 切割瓷砖 | 80-90dB |
| 电锯切割 | 85-95dB |
| 打磨墙面 | 70-85dB |

## 降噪措施

### 施工方
- 使用低噪音设备
- 高噪音工序集中在白天
- 关闭门窗施工
- 做好隔音处理

### 业主
- 提前通知邻居
- 与物业沟通施工时间
- 高噪音工序快速完成

## 法律规定

- 法定休息日、节假日禁止噪音施工
- 工作日 12:00-14:00 禁止噪音施工
- 违规可向环保部门投诉

## 邻里关系处理

- 装修前给邻居送小礼物
- 留下联系方式方便沟通
- 及时处理投诉
- 缩短高噪音工序时间

## 噪音投诉处理

### 投诉渠道
- **物业管理处**：第一时间联系，物业有权要求施工方停工整改
- **12345 市民热线**：向政府投诉，相关部门会派人处理
- **环保部门**：噪音超标可向当地环保局投诉
- **公安机关**：夜间严重噪音扰民可报警

### 法律规定
根据《环境噪声污染防治法》：
- 法定休息日、节假日全天，工作日 12:00-14:00，禁止产生噪声污染的装修作业
- 其他时段施工应采取降噪措施
- 违规施工可被处以 200-500 元罚款

## 被投诉时的应对（业主视角）

如果自家装修被邻居投诉：
1. **立即核实**：确认是否确实超出允许的施工时间
2. **主动沟通**：登门道歉，说明情况，承诺整改
3. **调整工序**：将高噪音工序集中在工作日白天完成
4. **赠送小礼物**：给受影响邻居送些水果或耳塞，表达歉意
5. **公示施工时间**：在楼道张贴施工时间表，让邻居心中有数

## 隔音装修建议

装修时可同步做好隔音，减少对他人的影响，也降低被投诉的概率：
- **墙面**：隔音毡 + 石膏板，降低 10-15dB
- **地面**：隔音垫 + 地板，降低 8-12dB
- **门窗**：双层中空玻璃 + 密封条，降低 15-20dB
- **管道**：隔音棉包裹下水管，降低流水噪音
