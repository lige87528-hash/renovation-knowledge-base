# 装修合同审查要点

## 基本信息审查
- [ ] 甲乙双方信息完整
- [ ] 工程地址正确
- [ ] 建筑面积正确

## 工程内容审查
- [ ] 承包范围明确
- [ ] 装修模式明确
- [ ] 报价清单作为附件

## 工期审查
- [ ] 开工日期明确
- [ ] 竣工日期明确
- [ ] 延期赔偿明确

## 质量标准审查
- [ ] 引用国家标准
- [ ] 隐蔽工程验收
- [ ] 竣工验收标准

## 付款方式审查
- [ ] 付款节点明确
- [ ] 付款比例合理（建议3-3-3-1）
- [ ] 增项约定（建议≤5%）

## 材料供应审查
- [ ] 甲方供材清单
- [ ] 乙方供材清单
- [ ] 材料品牌型号明确

## 违约责任审查
- [ ] 延期赔偿
- [ ] 质量赔偿
- [ ] 单方解约

## 质保条款审查
- [ ] 基础工程≥2年
- [ ] 水电工程≥5年
- [ ] 售后响应时间

## 合同审查常见遗漏

### 容易忽略的条款
- [ ] 是否约定了施工期间的安全责任归属
- [ ] 是否明确了材料进场的时间和验收标准
- [ ] 是否约定了工程变更的书面程序
- [ ] 是否明确了工程保修范围和保修期限起算时间
- [ ] 是否约定了争议解决方式（仲裁或诉讼）
- [ ] 是否约定了竣工结算的程序和时间

### 付款比例合理性判断
- **推荐比例**：30%-30%-30%-10%（开工-水电-泥木-竣工）
- **不合理比例**：开工付款超过 50%（风险过大）
- **尾款比例**：不低于 5%，最好 10%（质保金）

## 合同附件清单

以下文件应作为合同附件，与合同具有同等法律效力：
1. 完整报价清单（含材料品牌型号）
2. 设计图纸（平面图、施工图、水电图）
3. 材料进场验收标准
4. 施工工艺标准
5. 工程进度表
6. 甲乙双方身份证复印件
7. 施工方营业执照和资质证书复印件

## 签约建议

- 不要在销售人员催促下匆忙签约
- 签约前将合同发给有法律经验的朋友或律师审阅
- 所有空白处应划掉或填写"无"，防止事后添加
- 合同每页签字或盖章，防止替换页
- 保留合同原件，拍照备份电子版
