# 装修合同陷阱详解

## 常见合同陷阱

### 1. 模糊报价
报价单只写"XX 项目"，不写具体工艺、材料、规格。

**示例**：
- ❌ "铺地砖 ¥80/㎡"
- ✅ "铺地砖（东鹏800×800mm瓷砖，水泥砂浆铺贴，勾缝）¥80/㎡"

### 2. 恶意漏项
故意漏掉必要项目，后期以增项名义加收。

**常见漏项**：
- 地面找平
- 垃圾清运
- 材料搬运费
- 成品保护费

### 3. 拆分报价
把一个项目拆分成多个小项目，看起来单价便宜。

### 4. 付款比例不合理
前期付款比例过高，后期失去主动权。

**建议比例**：3-3-3-1

### 5. 无增项约定
合同中未约定增项比例上限。

**建议**：约定增项≤5%

## 合同审查清单

- [ ] 报价单是否明细
- [ ] 付款比例是否合理
- [ ] 是否有增项约定
- [ ] 质保期是否达标
- [ ] 是否有延期赔偿

## 合同条款逐条解读

### 工程概况条款
应包含：工程地址、建筑面积、承包范围、装修模式、设计图纸编号。
**避坑**：建筑面积应按实际施工面积计算，而非房产证建筑面积。

### 工程价款条款
应包含：合同总价、计价方式、付款节点和比例。
**避坑**：拒绝"按实际工程量结算"等模糊表述，要求明确总价或单价。

### 材料供应条款
应包含：甲乙双方各自供应的材料清单、品牌型号规格。
**避坑**：材料清单必须具体到品牌、型号、规格，不允许"同档次品牌"等模糊表述。

### 工期条款
应包含：开工日期、竣工日期、总天数、延期赔偿标准。
**避坑**：延期赔偿应明确具体金额或比例（建议每天总价的 0.1-0.3%）。

### 质量标准条款
应包含：参照的国家标准、验收标准、质保期限。
**避坑**：基础工程质保≥2年、水电≥5年，低于此标准的合同不要签。

### 付款方式条款
应包含：付款节点、付款比例、付款条件。
**避坑**：首付款不超过 30%，尾款不低于 10%，按进度付款。

### 违约责任条款
应包含：双方违约责任、赔偿标准、争议解决方式。
**避坑**：确认争议解决方式（诉讼或仲裁），选择对自己有利的方式。

## 签约前必做检查

- [ ] 对比 3 家以上报价，确认价格合理
- [ ] 实地考察施工方正在施工的工地
- [ ] 查看施工方营业执照和资质证书
- [ ] 确认合同中所有空白处已填写或划掉
- [ ] 合同每页签字或盖章
- [ ] 保留合同原件，拍照备份电子版
