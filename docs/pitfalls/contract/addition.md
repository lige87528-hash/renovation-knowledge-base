# 装修增项管理

## 增项类型

| 类型 | 原因 | 处理方法 |
|------|------|---------|
| 业主主动增项 | 需求变化 | 确认费用后再施工 |
| 施工方增项 | 漏项或设计变更 | 审核是否合理 |
| 客观增项 | 现场条件变化 | 协商分担费用 |

## 增项控制

### 事前控制
- 报价单细化
- 约定增项上限
- 书面确认

### 事中控制
- 增项确认单
- 明确费用
- 明确工期影响

### 事后控制
- 结算核对
- 分析增项原因
- 总结经验

## 增项确认单模板

```
工程增项确认单

增项原因：_____________
增项内容：_____________
增项费用：¥________

日期：____年____月____日
```

## 常见不合理增项

- 报价单已有项目重复收取
- 合同约定范围内收取增项
- 未提前确认费用的增项

## 不合理增项典型案例

### 案例一：水电恶意增项
某业主签约时报价水电改造 8000 元，施工中以"实际需要"为由增加至 15000 元。经核实，施工方初始报价时故意少算电线用量，属于恶意漏项。
**应对**：合同中约定"水电改造按实际用量结算，但不得超过报价的 10%"。

### 案例二：防水面积增项
报价单中只写了"卫生间防水"，施工时按墙面 1.8m 高度计算，超出业主预期面积。
**应对**：报价单中明确防水面积（地面 + 墙面高度），注明单价。

### 案例三：材料升级增项
施工方称"合同中的材料已停产"，推荐升级款，要求补差价。
**应对**：要求施工方提供停产证明，如无法提供，按合同执行；如确实停产，更换同档次产品不加价。

## 增项审核清单

收到增项通知时，逐项审核：

- [ ] 该增项是否在合同报价单中已有（重复收费）
- [ ] 该增项是否属于合同约定的施工范围
- [ ] 增项单价是否与市场合理价格一致
- [ ] 增项工程量是否准确（自行复核）
- [ ] 是否有更经济的替代方案
- [ ] 增项是否影响整体工期

## 增项谈判技巧

- 不要急于签字确认，要求 24 小时考虑时间
- 要求施工方提供增项的详细报价和计算依据
- 对比 2-3 家市场价格，判断报价是否合理
- 对于不合理增项，明确拒绝并说明理由
- 所有谈判结果写入增项确认单，双方签字
