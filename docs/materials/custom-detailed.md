# 全屋定制详解

## 定制类型

| 类型 | 包含内容 | 适用场景 |
|------|---------|---------|
| 橱柜定制 | 厨房地柜、吊柜 | 厨房 |
| 衣柜定制 | 卧室衣柜 | 卧室 |
| 书柜定制 | 书房书柜 | 书房 |
| 鞋柜定制 | 玄关鞋柜 | 玄关 |
| 全屋定制 | 所有柜体 | 全屋 |

## 板材选择

| 板材 | 特点 | 环保性 | 价格 |
|------|------|--------|------|
| 颗粒板 | 稳定性好 | E0/ENF | 中 |
| 多层板 | 防潮好 | E0/ENF | 中高 |
| 生态板 | 免漆环保 | E0/ENF | 高 |
| 密度板 | 可造型 | E1/E0 | 低 |

## 五金选择

| 配件 | 推荐品牌 | 说明 |
|------|---------|------|
| 铰链 | 百隆、海蒂诗 | 带缓冲 |
| 滑轨 | 百隆、海蒂诗 | 三节导轨 |
| 拉手 | 根据风格 | 隐形拉手流行 |

## 计价方式

### 投影面积计价
```
总价 = 投影面积 × 单价
```

### 展开面积计价
```
总价 = 各部件展开面积 × 单价
```

## 选购流程

1. 量尺
2. 设计
3. 选材料
4. 报价
5. 生产（15-30天）
6. 安装（1-3天）
7. 验收

## 全屋定制避坑指南

### 常见陷阱
- **低价引流**：用超低价吸引签约，实际报价不含五金、抽屉等
- **板材调包**：签约时说好 ENF 级板材，实际用 E1 级
- **五金减配**：标配普通铰链，升级进口铰链需额外加钱
- **增项收费**：抽屉、拉篮、灯带等全部单列收费

### 应对策略
1. 要求报价单列明所有费用（含五金、抽屉、拉篮）
2. 确认板材品牌、环保等级，写入合同
3. 五金品牌提前确认（百隆/海蒂诗/DTC）
4. 约定增项上限不超过总价 10%

## 知名品牌推荐

- **全国性品牌**：欧派、索菲亚、志邦、金牌、好莱客
- **区域性品牌**：本地品牌性价比可能更高，但需考察工厂和售后
- **五金品牌**：百隆（奥地利）、海蒂诗（德国）、DTC（国产）

## 验收要点

- 板材品牌、环保等级与合同一致
- 柜体平整，无翘曲变形
- 门板缝隙均匀（2-3mm）
- 五金开合顺畅，带缓冲
- 抽屉抽拉顺滑
- 封边平整，无开裂
