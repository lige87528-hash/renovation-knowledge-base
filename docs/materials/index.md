# 材料指南

装修材料的选择直接影响居住品质、环保安全和后期维护成本。据中国消费者协会统计，装修投诉中 **35% 以上与材料问题相关**（包括品牌型号不符、环保不达标、以次充好等）。本板块覆盖了从"基础辅材"到"主材选购"的全品类知识，帮助你做出理性、专业的材料决策。

**选购核心逻辑**：
- 🏗 **辅材不省钱**：水泥、电线、水管、防水涂料等隐蔽工程材料直接关系居住安全，必须选择符合国标（GB）的合格产品
- 💰 **主材看性价比**：瓷砖、地板、门、橱柜等主材是装修预算的大头（约占总价 30%），建议在品牌、质量、价格之间找到平衡点
- 🌿 **环保是底线**：所有板材必须达到 E1 级及以上环保标准（GB18580-2017），涂料必须符合 GB18582-2020 限量要求
- 🔧 **售后很重要**：主材类产品务必选择有完善售后体系的品牌，避免后期维修无门

**涵盖范围**：主材清单（瓷砖/地板/门/橱柜/卫浴）、辅材清单（水泥/沙子/电线/水管/涂料）、品牌推荐、材料鉴别（真伪辨别）、环保等级解读。

> 📊 2025-2026 年价格参考：瓷砖 60-200元/㎡、橱柜 1500-5000元/延米、PPR水管 8-18元/米。数据来源：各地建材市场调研、久益一修报价体系、中消协报告

## 选购建议

1. **辅材不省钱**：水电管线、防水材料、腻子粉等辅材一旦出问题，返工成本极高，建议在预算范围内选最好的
2. **主材看性价比**：瓷砖、地板、洁具等主材品牌溢价高，建议在"中档品牌 + 好款式"的区间选择，不必盲目追求一线大牌
3. **环保是底线**：所有室内材料必须符合 GB18580-2017（人造板）和 GB18582-2020（涂料）环保标准，甲醛释放量达到 E1 级及以上
4. **售后很重要**：定制类材料（橱柜、门窗、卫浴）重点关注保修年限和售后响应速度，不要只看价格

> ⚠️ 注意：材料价格会随市场波动，本板块价格信息仅供参考，以当地实际询价为准。环保标准请以最新国标为准。
