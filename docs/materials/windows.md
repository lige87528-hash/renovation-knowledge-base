# 窗户选购指南

## 窗户类型

| 类型 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| 平开窗 | 密封好 | 占空间 | 卧室、客厅 |
| 推拉窗 | 不占空间 | 密封一般 | 阳台、厨房 |
| 内倒窗 | 通风好 | 价格高 | 卧室 |
| 固定窗 | 采光好 | 不能开 | 客厅大窗 |

## 窗户选购补充要点

### 窗型选择建议
- **卧室**：推荐平开窗 + 内倒功能，密封好且通风
- **客厅**：大面积推拉窗或平开窗，采光优先
- **厨房**：推拉窗，不占操作空间
- **卫生间**：小平开窗或固定窗 + 排气扇

### 断桥铝选购要点
- **型材壁厚**：新国标要求≥1.8mm（2021 年起）
- **隔热条**：认准 PA66 尼龙隔热条（不要用 PVC）
- **密封条**：三元乙丙（EPDM）密封条，耐老化
- **角部工艺**：注胶角码工艺优于机械连接

### 五金品牌推荐
- 进口：诺托（ROTO）、丝吉利娅（SIEGENIA）、好博（HOPPE）
- 国产：坚朗、合和、春光

### 安装验收要点
- [ ] 窗框与墙体之间填充发泡胶饱满
- [ ] 外侧防水胶打胶完整
- [ ] 窗扇开合顺畅，无卡顿
- [ ] 密封条无遗漏、无变形
- [ ] 排水孔畅通
- [ ] 玻璃 3C 标志清晰
