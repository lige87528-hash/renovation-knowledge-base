# 装修环保材料指南

## 环保标准

| 标准 | 甲醛释放量 | 说明 |
|------|-----------|------|
| ENF级 | ≤0.025mg/m³ | 最高标准 |
| E0级 | ≤0.050mg/m³ | 推荐标准 |
| E1级 | ≤0.124mg/m³ | 国标底线 |

## 环保材料选择

### 板材
- 实木板 > 多层板 > 颗粒板
- 选择ENF级
- 避免密度板

### 涂料
- 水性漆 > 油性漆
- VOC含量≤50g/L
- 十环认证

### 胶水
- 环保胶
- 减少使用量
- 物理连接替代

## 环保材料选购清单

### 必查认证标志
- **中国环境标志（十环认证）**：国内最权威的环保产品认证
- **法国 A+ 认证**：国际认可的室内空气排放标准
- **GREENGUARD 金级**：美国绿色卫士认证，适合儿童房
- **FSC 森林认证**：确保木材来自可持续管理的森林

### 各空间环保材料推荐

#### 客厅
- 地面：实木复合地板（ENF 级）或抛光砖
- 墙面：水性乳胶漆（VOC ≤ 50g/L）
- 吊顶：轻钢龙骨 + 石膏板（减少木工板和胶水）

#### 卧室
- 地面：实木地板或多层实木复合地板
- 墙面：硅藻泥或水性乳胶漆
- 家具：实木家具或 ENF 级板材定制

#### 厨房
- 地面：防滑釉面砖
- 墙面：釉面砖（易清洁）
- 橱柜：E0 级多层板柜体 + 石英石台面

#### 卫生间
- 地面：防滑砖（摩擦系数 ≥ 0.5）
- 墙面：釉面砖
- 防水：聚氨酯防水涂料（环保型）

| 材料 | 普通款价格 | 环保款价格 | 差价 |
|------|-----------|-----------|------|
| 板材（全屋） | 8000元 | 12000元 | +4000元 |
| 涂料（全屋） | 1500元 | 2500元 | +1000元 |
| 胶水辅料 | 500元 | 1000元 | +500元 |
| **合计** | | | **+5500元** |

这笔投入换来的是家人健康，从长远看完全值得。

## 环保施工

- 减少胶水使用
- 做好通风
- 材料分类存放
