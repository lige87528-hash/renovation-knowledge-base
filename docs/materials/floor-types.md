# 地板种类详解

## 按材质分类

| 类型 | 特点 | 价格 | 适用场景 |
|------|------|------|---------|
| 实木地板 | 天然环保 | 200-800/㎡ | 卧室、书房 |
| 实木复合 | 稳定性好 | 150-400/㎡ | 客厅、卧室 |
| 强化地板 | 耐磨便宜 | 80-200/㎡ | 客厅、书房 |
| SPC石塑 | 防水环保 | 80-180/㎡ | 厨卫、阳台 |

## 按安装方式分类

| 方式 | 特点 |
|------|------|
| 锁扣式 | 安装简便 |
| 平扣式 | 需要胶水 |
| 龙骨式 | 实木专用 |

## 选购要点

1. 环保等级（ENF > E0 > E1）
2. 耐磨转数（家用≥6000转）
3. 含水率（8-13%）
4. 表面质量（无划痕、无变形）

## 各类地板详细对比

### 实木地板
- **优点**：天然环保、脚感舒适、可翻新、寿命长（30年以上）
- **缺点**：价格高、需定期保养、怕潮湿、易变形
- **常见树种**：橡木、胡桃木、樱桃木、柚木、枫木
- **价格参考**：橡木 200-400元/㎡，胡桃木 400-800元/㎡
- **选购要点**：关注含水率（应与当地平衡含水率接近，北方 8-10%，南方 10-13%）

### 实木复合地板
- **优点**：稳定性好、不易变形、价格适中、安装简便
- **缺点**：不可翻新、环保性不如实木
- **结构**：表层实木（2-4mm）+ 多层胶合板基材
- **价格参考**：150-400元/㎡
- **选购要点**：表层越厚越接近实木，环保等级优先选 ENF

### 强化地板
- **优点**：耐磨、价格便宜、花色多、易打理
- **缺点**：脚感硬、不可翻新、怕水泡、环保性一般
- **结构**：耐磨层 + 装饰层 + 高密度基材 + 平衡层
- **价格参考**：80-200元/㎡
- **选购要点**：耐磨转数≥6000转（家用），吸水厚度膨胀率≤2.5%

### SPC石塑地板
- **优点**：100%防水、零甲醛、超薄（4-6mm）、可直接铺在旧瓷砖上
- **缺点**：脚感偏硬、耐高温性差
- **价格参考**：80-180元/㎡
- **选购要点**：关注耐磨层厚度（0.3-0.5mm）和锁扣质量

## 安装注意事项

- 地板铺设前地面含水率应≤3%（水泥地面）或≤10%（木地面）
- 铺设时应留 8-12mm 伸缩缝
- 实木地板需要打龙骨，复合地板可直接铺设
- 安装后 48 小时内避免重物踩踏和大量水分接触
