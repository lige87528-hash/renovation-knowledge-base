# 瓷砖种类详解

## 按材质分类

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 抛光砖 | 表面光亮、硬度高 | 客厅地面 |
| 釉面砖 | 花色丰富、防滑 | 厨卫墙地面 |
| 通体砖 | 正反面一致、耐磨 | 阳台、走廊 |
| 玻化砖 | 吸水率低、硬度高 | 客厅地面 |
| 马赛克 | 装饰性强 | 背景墙 |

## 按用途分类

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 地砖 | 防滑、耐磨 | 地面 |
| 墙砖 | 轻薄、美观 | 墙面 |
| 厨卫砖 | 防水、防滑 | 厨卫 |
| 户外砖 | 耐候、防滑 | 阳台、花园 |

## 选购要点

1. 看表面是否平整
2. 听声音是否清脆
3. 试吸水率是否达标
4. 测防滑性是否合格

## 各类瓷砖详解

### 抛光砖
- **工艺**：通体砖坯表面抛光而成
- **规格**：常见 600×600mm、800×800mm、1000×1000mm
- **价格**：40-120 元/㎡
- **适用**：客厅、走廊等干燥区域地面
- **注意**：遇水易滑，不适合厨卫地面

### 釉面砖
- **工艺**：表面施釉烧制，花色丰富
- **规格**：墙砖 300×600mm、地砖 600×600mm
- **价格**：50-200 元/㎡
- **适用**：厨卫墙地面、阳台
- **注意**：釉面硬度有限，避免硬物碰撞

### 通体砖
- **工艺**：表面和坯体材质一致
- **规格**：常见 600×600mm
- **价格**：40-100 元/㎡
- **适用**：阳台、走廊、户外
- **注意**：防滑性好但花色单一

### 玻化砖
- **工艺**：高温烧制，全瓷化
- **规格**：常见 800×800mm、1000×1000mm
- **价格**：60-180 元/㎡
- **适用**：客厅地面
- **注意**：吸水率极低（≤0.5%），耐磨度高

### 大板/岩板
- **工艺**：大规格、薄型化
- **规格**：600×1200mm、750×1500mm、900×1800mm
- **价格**：150-500 元/㎡
- **适用**：客厅地面、背景墙、台面
- **注意**：需专业铺贴，辅料成本高

## 铺贴方式

| 方式 | 特点 | 工费 |
|------|------|------|
| 正铺 | 最常用，省砖省工 | 30-45元/㎡ |
| 斜铺 | 美观，耗材约多10% | 45-60元/㎡ |
| 人字铺 | 效果好，耗材约多15% | 60-80元/㎡ |
| 混铺 | 多规格搭配 | 60-100元/㎡ |
