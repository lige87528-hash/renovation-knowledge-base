# 装修材料选购指南

## 选购原则

1. 环保优先
2. 质量第一
3. 价格适中
4. 品牌保障

## 选购流程

1. 确定预算
2. 了解材料
3. 对比品牌
4. 实地考察
5. 签订合同

## 选购技巧

### 瓷砖
- 看平整度
- 听声音
- 试吸水率
- 测防滑性

### 地板
- 看环保等级
- 检查含水率
- 测试耐磨性

### 涂料
- 看环保标识
- 闻气味
- 查检测报告

### 卫浴
- 看釉面
- 检查水件
- 确认配件

## 选购渠道

| 渠道 | 优点 | 缺点 |
|------|------|------|
| 建材市场 | 可看实物 | 价格不透明 |
| 品牌店 | 品质保障 | 价格高 |
| 电商 | 价格透明 | 无法看实物 |

## 各材料选购详解

### 瓷砖选购要点
- **看平整度**：两块砖面对面贴合，缝隙应均匀
- **听声音**：敲击声音清脆说明密度高
- **试吸水率**：滴水测试，吸水慢说明质量好（瓷质砖吸水率≤0.5%）
- **测防滑性**：在砖面倒水测试，摩擦系数≥0.5 为防滑合格
- **看批次**：同一空间用同一批次产品，避免色差
- **买余量**：多买 5-10%，后期补货可能批次不同

### 地板选购要点
- **环保等级**：优先选 ENF 级（甲醛≤0.025mg/m³）
- **含水率**：与当地平衡含水率接近（北方 8-10%，南方 10-13%）
- **耐磨转数**：家用≥6000 转，商用≥9000 转
- **表面质量**：无划痕、无变形、无色差

### 涂料选购要点
- **环保标识**：十环认证、法国 A+、GREENGUARD
- **VOC 含量**：≤50g/L 为优质
- **开盖检查**：无硬皮、无分层、无异味
- **颜色选择**：小面积试色后再大面积涂刷

### 卫浴选购要点
- **釉面**：光滑无针孔，滴水成珠
- **水件**：按动顺畅，回弹有力（推荐吉博力、威迪亚）
- **陶瓷体**：重量沉说明密度高
- **坑距**：测量马桶排污口中心到墙面距离（305mm 或 400mm）

## 采购渠道对比与建议

| 材料 | 推荐渠道 | 理由 |
|------|---------|------|
| 瓷砖 | 建材市场 | 看实物、比花色、可退货 |
| 地板 | 品牌专卖店 | 包安装、有售后 |
| 涂料 | 品牌授权店/旗舰店 | 防伪验证 |
| 卫浴 | 建材市场/品牌店 | 看实物、包安装 |
| 灯具 | 网购 | 标准化产品，价格透明 |
| 开关插座 | 网购旗舰店 | 标准化，价格比线下便宜 20% |
| 窗帘 | 网购定制 | 价格比线下便宜 40-60% |
