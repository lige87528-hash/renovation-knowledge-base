# 装修行业术语大全

## 施工术语

| 术语 | 含义 |
|------|------|
| 基层处理 | 施工前对基础表面的处理 |
| 找平 | 使地面平整的施工 |
| 闭水试验 | 防水施工后蓄水检验 |
| 打压测试 | 水管施工后压力测试 |
| 隐蔽工程 | 被封在内部的工程 |
| 横平竖直 | 管线铺设的基本要求 |
| 走顶 | 管线从天花板走 |

## 材料术语

| 术语 | 含义 |
|------|------|
| E0级 | 甲醛释放量≤0.05mg/m³ |
| ENF级 | 甲醛释放量≤0.025mg/m³ |
| PPR管 | 家装水管常用材料 |
| PVC管 | 电线管常用材料 |
| 石膏板 | 吊顶和隔墙常用材料 |

## 设计术语

| 术语 | 含义 |
|------|------|
| 平面布置图 | 展示空间布局的图纸 |
| 立面图 | 展示墙面设计的图纸 |
| 效果图 | 装修后的效果预览 |
| 施工图 | 指导施工的图纸 |

## 合同术语

| 术语 | 含义 |
|------|------|
| 增项 | 合同约定之外的额外项目 |
| 质保金 | 预留的质量保证金 |
| 工期 | 施工总时间 |
| 验收 | 检查施工质量 |

## 预算报价术语

| 术语 | 含义 |
|------|------|
| 半包 | 施工方负责施工和辅材，业主自购主材 |
| 全包 | 施工方负责设计、施工和所有材料 |
| 整装 | 全包 + 家具 + 家电 + 软装 |
| 清包 | 业主自购所有材料，施工方只负责人工 |
| 延米 | 橱柜计价单位，1延米=1米长度 |
| 展开面积 | 按实际展开面积计算（如柜体） |
| 投影面积 | 按正面投影面积计算（如衣柜） |

## 材料规格术语

| 术语 | 含义 |
|------|------|
| 4分管 | 直径约20mm的水管 |
| 6分管 | 直径约25mm的水管 |
| BV线 | 铜芯聚氯乙烯绝缘电线 |
| BVR线 | 铜芯聚氯乙烯绝缘软电线 |
| 耐水腻子 | N型腻子，防潮防霉 |
| 86型底盒 | 标准开关插座底盒（86×86mm） |
| 轻钢龙骨 | 吊顶和隔墙的金属骨架 |

## 常见缩写

| 缩写 | 全称 | 含义 |
|------|------|------|
| PVC | Polyvinyl Chloride | 聚氯乙烯，电线管材料 |
| PPR | Polypropylene Random | 无规共聚聚丙烯，水管材料 |
| VOC | Volatile Organic Compounds | 挥发性有机化合物 |
| BIM | Building Information Modeling | 建筑信息模型 |
| ENF | Emission Non-Formaldehyde | 无醛添加级（板材环保等级） |
| JS | 聚合物水泥 | JS防水涂料 |

## 快速学习建议

装修前重点掌握：半包/全包/整装的区别、E0/ENF 环保等级、隐蔽工程、增项、验收标准这 5 个核心概念，就能避免大部分常见坑。
