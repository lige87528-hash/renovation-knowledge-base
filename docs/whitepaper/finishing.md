# 装修收尾工作

## 收尾内容

### 开荒保洁
- 清除装修垃圾
- 清洁地面、墙面
- 清洁门窗
- 清洁厨卫

### 家具进场
- 按设计摆放
- 检查是否有损坏
- 调试功能

### 家电安装
- 空调安装
- 洗衣机安装
- 冰箱就位
- 电视安装

### 软装搭配
- 窗帘安装
- 灯具安装
- 装饰画挂放
- 绿植摆放

## 验收要点

- [ ] 所有功能正常
- [ ] 无损坏
- [ ] 清洁到位
- [ ] 家具摆放正确

## 入住前准备

- 通风除甲醛
- 空气检测
- 确认水质
- 确认燃气安全

## 开荒保洁详解

### 保洁内容清单
- **地面清洁**：清除水泥渣、胶渍、油漆点
- **玻璃清洁**：窗框、玻璃双面清洁
- **墙面清洁**：清除腻子粉尘、油漆飞溅
- **厨卫清洁**：清除瓷砖缝隙水泥渍、洁具表面污渍
- **柜体清洁**：内部外部全面清洁
- **五金清洁**：开关面板、门把手、水龙头抛光清洁

### 保洁方式选择
- **自行保洁**：节省 1000-3000 元，但需要 1-2 天时间和清洁工具
- **专业保洁**：5-10 元/㎡，100㎡ 约 500-1000 元，专业工具效率高

## 家具家电进场顺序

1. **大件家具先行**：沙发、床、餐桌等
2. **家电安装**：空调、热水器（需专业安装）
3. **窗帘安装**：在家具进场后安装，避免磕碰
4. **灯具安装**：最后安装，方便调试
5. **小件软装**：装饰画、绿植、摆件等最后摆放

## 通风除甲醛详细方案

### 最佳通风时机
- 装修完成后立即开始通风
- 夏季高温高湿，甲醛释放最快，是通风黄金期
- 冬季建议开启暖气加速甲醛释放后再通风

### 通风方法
- **自然通风**：打开所有门窗，持续 3-6 个月
- **工业风扇辅助**：在房间内放置工业风扇加速空气流动
- **新风系统**：装修时预埋，入住后持续使用
- **入住后**：每天开窗通风至少 2 小时

### 检测标准
- 封闭 12 小时后检测
- 甲醛 ≤ 0.08mg/m³（建议值）
- 苯 ≤ 0.09mg/m³
- TVOC ≤ 0.50mg/m³
