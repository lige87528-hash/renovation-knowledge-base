# 装修完工入住指南

## 开荒保洁

### 保洁内容
- 清除装修垃圾
- 清洁地面、墙面
- 清洁门窗
- 清洁厨卫
- 清洁灯具

### 保洁标准
- 地面无灰尘
- 玻璃无污渍
- 厨卫无死角

## 通风除甲醛

### 方法
| 方法 | 效果 | 说明 |
|------|------|------|
| 通风 | 最有效 | 至少3个月 |
| 活性炭 | 辅助 | 定期更换 |
| 空气净化器 | 辅助 | 持续运行 |

### 建议
- 夏季通风效果更好
- 新房至少通风3个月
- 有小孩建议6个月

## 空气检测

### 检测指标
| 指标 | 标准 | 建议值 |
|------|------|--------|
| 甲醛 | ≤0.10mg/m³ | ≤0.08mg/m³ |
| 苯 | ≤0.11mg/m³ | ≤0.08mg/m³ |
| TVOC | ≤0.60mg/m³ | ≤0.50mg/m³ |

## 入住条件

- [ ] 环保检测达标
- [ ] 水电正常
- [ ] 厨卫正常
- [ ] 门窗正常
- [ ] 保洁完成

## 入住准备清单

### 生活用品采购
- [ ] 床上用品（床单、被套、枕头、被子）
- [ ] 厨房用品（锅碗瓢盆、刀具、砧板）
- [ ] 卫浴用品（毛巾、浴巾、拖鞋、牙刷）
- [ ] 清洁用品（扫把、拖把、垃圾袋、洗洁精）
- [ ] 日常用品（纸巾、垃圾袋、衣架）

### 安全检查
- [ ] 燃气管道检查（联系燃气公司开通）
- [ ] 电路安全检查（每个插座通电测试）
- [ ] 水路安全检查（每个水龙头放水检查）
- [ ] 门窗锁具检查（更换锁芯）
- [ ] 阳台栏杆检查（高度≥1.1m，间距≤11cm）

### 网络通信
- [ ] 宽带安装（提前 1 周预约）
- [ ] 电视信号开通
- [ ] 手机号码变更通知（如有）

## 入住后注意事项

### 第一个月
- 持续每天开窗通风至少 2 小时
- 观察墙面是否有裂纹出现
- 检查水管接头是否有渗漏
- 记录水电使用量，建立基准数据

### 前半年
- 每季度检查一次防水（看楼下天花板）
- 检查门窗密封条是否老化
- 检查地板是否有起翘
- 检查墙面油漆是否有裂纹

### 日常维护
- 每半年清洁一次空调滤网
- 每年检查一次燃气管道
- 每 2 年检查一次防水层
- 发现小问题及时处理，避免扩大
