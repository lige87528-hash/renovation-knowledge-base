# 甲醛治理指南

## 甲醛来源

| 来源 | 甲醛含量 | 释放周期 |
|------|---------|---------|
| 人造板 | 高 | 3-15年 |
| 胶水 | 高 | 1-5年 |
| 涂料 | 低 | 3-6个月 |
| 家具 | 中 | 1-3年 |
| 窗帘布艺 | 低 | 1-3个月 |

## 甲醛危害

- 刺激眼睛和呼吸道
- 引起过敏反应
- 长期接触增加患癌风险
- 对孕妇和儿童影响更大

## 治理方法

### 有效方法
| 方法 | 效果 | 费用 | 说明 |
|------|------|------|------|
| 通风 | 最有效 | 免费 | 至少3个月 |
| 活性炭 | 辅助 | 低 | 定期更换 |
| 空气净化器 | 辅助 | 中 | 选择除甲醛款 |
| 绿植 | 微弱 | 低 | 心理安慰为主 |

### 专业治理
| 方法 | 效果 | 费用 | 说明 |
|------|------|------|------|
| 光触媒 | 较好 | 10-30元/㎡ | 需专业公司 |
| 甲醛清除剂 | 短期 | 5-15元/㎡ | 效果不持久 |
| 臭氧治理 | 较好 | 10-20元/㎡ | 需专业人员 |

## 治理流程

1. 装修完工后封闭门窗12小时
2. 请专业机构检测甲醛浓度
3. 根据检测结果选择治理方案
4. 治理后再次检测
5. 达标后入住

## 国家标准

| 标准 | 甲醛限值 |
|------|---------|
| GB/T 18883 | ≤0.10mg/m³ |
| GB 50325 | ≤0.08mg/m³ |

建议值：≤0.08mg/m³ 以下入住

## 装修各阶段甲醛控制

### 设计阶段
- 减少人造板使用量，优先选实木或 ENF 级板材
- 简约设计，减少胶水使用
- 避免过度装修，材料越少甲醛源越少

### 材料选购
- 板材选 ENF 级（甲醛≤0.025mg/m³）
- 涂料选水性漆，VOC ≤ 50g/L
- 胶水选环保型，减少用量
- 家具选实木或金属框架

### 施工阶段
- 监督施工方使用合同约定的环保材料
- 减少现场胶水使用
- 施工期间保持通风

### 治理阶段
- 通风是最有效的方法，持续 3-6 个月
- 夏季高温期甲醛释放最快，是治理黄金期
- 工业风扇辅助加速空气流通
- 入住前请 CMA 认证机构检测

## 常见除甲醛误区

| 误区 | 真相 |
|------|------|
| 放柚子皮能除甲醛 | 只能掩盖气味，不能去除甲醛 |
| 放几盆绿萝就够了 | 植物净化能力极其有限 |
| 没味道就安全了 | 甲醛低浓度时无色无味，需仪器检测 |
| 活性炭能长期吸附 | 活性炭 2-3 周饱和，需定期更换 |
| 光触媒一次搞定 | 需要紫外线持续照射，效果有限 |

## 室内空气质量检测

### 检测时机
- 装修完成后封闭 12 小时检测
- 最好在入住前 1 个月检测

### 检测机构选择
- 认准 CMA 认证（中国计量认证）
- 避免选择既检测又治理的机构（可能有利益冲突）
- 检测费用约 300-500 元/点（每房间一个检测点）

### 检测指标
| 指标 | 国标限值 | 建议值 |
|------|---------|-------|
| 甲醛 | ≤0.10mg/m³ | ≤0.08mg/m³ |
| 苯 | ≤0.11mg/m³ | ≤0.08mg/m³ |
| TVOC | ≤0.60mg/m³ | ≤0.50mg/m³ |
| 氨 | ≤0.20mg/m³ | ≤0.15mg/m³ |
