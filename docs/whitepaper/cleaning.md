# 开荒保洁指南

## 保洁内容

### 基础保洁
- 清除装修垃圾
- 清洁地面
- 清洁墙面
- 清洁门窗
- 清洁厨卫

### 深度保洁
- 玻璃清洁
- 灯具清洁
- 柜体内部清洁
- 空调清洗

## 保洁工具

| 工具 | 用途 |
|------|------|
| 吸尘器 | 地面除尘 |
| 玻璃刮 | 玻璃清洁 |
| 抹布 | 擦拭 |
| 清洁剂 | 去污 |
| 铲刀 | 清除胶痕 |

## 保洁顺序

1. 顶面 → 墙面 → 地面
2. 里面 → 外面
3. 厨房 → 卫生间 → 其他房间

## 验收要点

- 地面无灰尘
- 玻璃无污渍
- 厨卫无死角
- 门窗无胶痕

## 保洁注意事项

### 地面清洁
- **瓷砖地面**：先用吸尘器清除灰尘，再用湿拖把清洁
- **木地板**：用半干的拖把，避免水分过多导致地板变形
- **石材地面**：使用中性清洁剂，避免酸性清洁剂腐蚀

### 玻璃清洁
- 先用铲刀清除胶痕和水泥点
- 喷玻璃清洁剂，用玻璃刮从上到下刮净
- 窗框缝隙用湿巾或棉签清洁

### 厨卫清洁重点
- **瓷砖缝隙**：用旧牙刷 + 清洁剂刷洗
- **洁具表面**：用中性清洁剂，避免划伤釉面
- **橱柜内部**：用干布擦拭，注意防潮

### 不建议自行处理的情况
- 高空外窗清洁（安全第一，请专业人员）
- 大面积胶渍清除（可能需要专业溶剂）
- 大理石地面结晶处理（需要专业设备）

## 保洁公司选择

### 选择标准
- 有营业执照和清洁服务资质
- 有保洁保险（防止清洁过程中损坏物品）
- 使用环保清洁剂
- 有明确的验收标准
