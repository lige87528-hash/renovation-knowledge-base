# 拎包入住

拎包入住是整装的升级版本，连软装配饰（装饰画、摆件、床品）都配齐，真正实现"提包入住"。

## 与整装的区别

| 对比项 | 整装 | 拎包入住 |
|--------|------|---------|
| 设计施工 | ✅ | ✅ |
| 主辅材料 | ✅ | ✅ |
| 家具家电 | ✅ | ✅ |
| 软装搭配 | 部分 | ✅ |
| 装饰品 | ❌ | ✅ |
| 日用品 | ❌ | ✅ |

## 适合人群

- 投资房出租，希望快速回本
- 异地购房，无法现场采购
- 预算充足，追求极致省心

## 费用参考

拎包入住价格一般在 3000-5000 元/㎡ 以上。以 100㎡ 房屋为例：
- 经济型拎包入住：约 30-40 万元
- 舒适型拎包入住：约 40-60 万元
- 高端型拎包入住：约 60-100 万元

## 选择拎包入住的注意事项

1. **确认清单范围**：合同中必须详细列出所有包含的物品清单，具体到品牌、型号、数量
2. **软装品味**：软装搭配直接影响居住体验，要求设计师提供搭配方案并确认
3. **家电能效等级**：确认所有家电的能效等级，高能效长期使用更省钱
4. **家具环保指标**：新家具是甲醛的重要来源，要求提供环保检测报告
5. **售后分工**：明确哪些由装修公司负责，哪些由家具/家电厂家负责

## 真实案例

成都业主张先生在海南购买了一套 80㎡ 度假房，选择拎包入住模式。从签约到交付仅用了 45 天，所有家具家电软装全部到位。总价 35 万元，相比自己异地采购节省了约 3 万元的交通和时间成本，且风格统一协调。

## 拎包入住包含物品清单（参考）

### 家具类
沙发、茶几、电视柜、餐桌、餐椅、床、床垫、衣柜、床头柜、书桌

### 家电类
空调、冰箱、洗衣机、电视、烟灶、热水器、微波炉

### 软装类
窗帘、灯具、装饰画、摆件、地毯、床品四件套

### 日用品类
毛巾、拖鞋、垃圾桶、衣架、厨房小工具

> 不同公司提供的清单可能有所不同，签约前务必逐项确认。
