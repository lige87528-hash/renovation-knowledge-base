# 半包

## 什么是半包

半包是指装修公司负责施工和辅材（水泥、沙子、电线、水管等），业主自己购买主材（瓷砖、地板、门、橱柜等）。

## 优缺点分析

### 优点
- **性价比平衡**：比清包省心，比全包省钱
- **主材自主**：核心材料自己选，品质和风格可控
- **施工有保障**：装修公司负责施工质量和辅材

### 缺点
- **仍需花时间**：需要自己选购主材
- **主材超预算风险**：选材料时容易升级超出预算

## 适合人群

- 有一定装修知识但不想太操心
- 周末有时间逛建材市场
- 希望控制预算又不想完全自己干

## 费用参考

半包价格一般在 500-800 元/㎡（含人工+辅材），主材费用另算。

## 半包费用详细构成

### 装修公司收取部分（500-800元/㎡）

| 项目 | 单价 | 说明 |
|------|------|------|
| 拆除工程 | 30-60元/㎡ | 拆墙、铲墙皮、拆旧瓷砖 |
| 水电改造 | 50-80元/m | 含电线、水管、穿管 |
| 防水工程 | 50-80元/㎡ | 卫生间、厨房、阳台 |
| 泥瓦工程 | 35-60元/㎡ | 贴砖、找平 |
| 木作工程 | 80-150元/㎡ | 吊顶、背景墙、柜体基层 |
| 油漆工程 | 25-45元/㎡ | 腻子+乳胶漆（3遍腻子+2遍漆） |
| 管理费 | 总价的5-10% | 项目管理、协调 |

### 业主自购主材费用参考（100㎡）

| 项目 | 经济型 | 舒适型 | 高端型 |
|------|-------|-------|-------|
| 瓷砖 | 4000-6000元 | 6000-12000元 | 12000-25000元 |
| 地板 | 3000-5000元 | 5000-10000元 | 10000-20000元 |
| 门（3-4扇） | 2000-4000元 | 4000-8000元 | 8000-20000元 |
| 橱柜 | 3000-5000元 | 5000-12000元 | 12000-30000元 |
| 卫浴 | 3000-5000元 | 5000-10000元 | 10000-25000元 |

## 半包主材采购时间表

| 施工阶段 | 需提前采购的主材 | 提前时间 |
|---------|----------------|---------|
| 开工前 | 确认瓷砖、地板型号 | 2-3周 |
| 水电阶段 | 确认开关插座面板、前置过滤器 | 1周 |
| 泥瓦阶段 | 瓷砖进场、地漏 | 3-5天 |
| 木作阶段 | 确认门、橱柜尺寸 | 1-2周（定制需要生产周期） |
| 油漆阶段 | 乳胶漆进场 | 2-3天 |
| 安装阶段 | 门、橱柜、卫浴、灯具 | 1周前预约 |

## 半包 vs 全包 真实费用对比

以 100㎡ 中档装修为例：
- **半包**：施工费 7 万 + 主材 8 万 = 15 万，业主花时约 30-50 天采购
- **全包**：18-22 万（含管理费），业主花时约 5-10 天确认方案
- **差价**：约 3-7 万，相当于业主用自己的时间换取的回报
