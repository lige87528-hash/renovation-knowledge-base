# 整装

整装 = 全包 + 家具 + 家电 + 软装，真正实现拎包入住。

## 特点

- 设计、施工、主材、辅材、家具、家电、窗帘、灯具全部包含
- 一站式服务，业主只需确认方案和付款
- 适合预算充足、追求品质的业主

## 费用参考

整装价格一般在 2000-4000 元/㎡ 以上。

## 费用构成详解

整装的费用可以拆分为以下几个部分：

| 项目 | 占比 | 说明 |
|------|------|------|
| 设计费 | 3-5% | 含方案设计、施工图、效果图 |
| 施工费 | 25-30% | 人工+辅材+管理费 |
| 主材费 | 30-35% | 瓷砖、地板、门、卫浴等 |
| 家具费 | 15-20% | 沙发、床、餐桌椅、衣柜等 |
| 家电费 | 10-15% | 空调、冰箱、洗衣机、烟灶等 |
| 软装费 | 5-10% | 窗帘、灯具、装饰画、床品等 |

以 100㎡ 房屋为例，舒适型整装总价约 20-30 万元。

## 选择整装公司的关键点

1. **看样板间**：不要只看效果图，要求参观实际完工的样板间或已交付工地
2. **看材料清单**：合同中必须列明所有材料的品牌、型号、规格，避免"同档次品牌替换"等模糊表述
3. **看增项条款**：约定增项不得超过总价 5%，超出部分由装修公司承担
4. **看售后保障**：确认质保期限（基础工程 2 年、水电 5 年）和售后响应时间
5. **看付款方式**：建议按 30%-30%-30%-10% 的比例分阶段付款，保留 10% 尾款作为质保金

## 真实案例

北京朝阳区业主李女士，100㎡ 三居室选择整装模式，签约价 25 万元。施工方提供的材料清单中瓷砖标注为"国内一线品牌"，实际进场为某三线品牌。李女士通过合同中的品牌型号条款，要求更换为合同中约定的品牌，避免了约 8000 元的材料差价损失。

## 整装 vs 全包的额外价值

整装相比全包多出的价值在于：
- 家具家电统一采购，风格更协调
- 批量采购享受集团议价，单件成本低于业主自购
- 一站式售后，不需要分别联系家具厂家和家电售后
- 软装设计师搭配，整体效果更有保障

## 整装注意事项

- 签约前要求查看材料展厅，确认套餐内可选材料的实际品质
- 要求提供完整报价清单，不要只看总价
- 合同中明确家具家电的品牌型号，不接受"同档次替换"
- 确认交付标准：哪些物品包含在内，哪些需要自购
- 建议安装第三方监理，全程监督施工质量
- 验收时逐项核对材料清单和家具家电清单
