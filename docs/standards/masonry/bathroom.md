# 卫生间装修注意事项

## 布局设计

### 干湿分离
- 淋浴区与洗漱区分开
- 用浴帘或玻璃隔断
- 小户型用浴帘+挡水条

### 最小尺寸
| 区域 | 最小尺寸 |
|------|---------|
| 马桶区 | 宽度≥80cm |
| 洗漱区 | 宽度≥60cm |
| 淋浴区 | 最小80×80cm |

## 防水要点

- 地面全做防水
- 墙面淋浴区≥1.8m
- 管根加强处理
- 门槛石防水处理

## 通风排水

- 排风扇风量≥100m³/h
- 地面向地漏找坡1-2%
- 地漏选择防臭型

## 电路预留

- 镜前灯插座
- 智能马桶插座
- 电热毛巾架插座
- 所有插座带防溅盒

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第6章防水工程和第9章地面工程
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第6.4节卫生间防水要求
- **GB 50096-2011**《住宅设计规范》：第5.7节卫生间最小使用面积和尺寸要求
- **JGJ 367-2015**《住宅装饰装修室内环境污染控制标准》：卫生间通风换气量要求

## 施工 SOP 流程

1. **布局设计**：根据卫生间尺寸和使用习惯，确定马桶、洗手台、淋浴区位置，画出平面布置图
2. **水电预埋**：按布置图预埋给水管、排水管、电线管，预留镜前灯、智能马桶等插座
3. **防水施工**：地面全做防水，墙面淋浴区≥1.8m，其他区域≥0.3m，管根做附加层
4. **闭水试验**：蓄水24小时，确认无渗漏后进行下一道工序
5. **地面找坡**：向地漏方向找坡1-2%，坡度均匀无倒坡
6. **墙面贴砖**：从地面开始由下至上铺贴，墙砖压地砖
7. **地面贴砖**：地漏处做八字角，周边砖向地漏方向倾斜
8. **洁具安装**：安装马桶、洗手台、淋浴设备，调试排水通畅

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 地面找坡方向错误 | 坡向地漏，坡度1-2% | 积水、排水不畅 |
| 墙砖地砖不压缝 | 墙砖压地砖（地压墙） | 水从墙地砖缝隙渗入地面 |
| 地漏不是最低点 | 地漏处做八字角，是最低点 | 积水排不干净 |
| 卫生间门套不做防潮 | 门套底部涂刷防水涂料或做挡水坎 | 门套受潮腐烂 |
| 插座不带防溅盒 | 所有卫生间插座使用防溅型 | 水汽进入短路 |
| 排风口直接排到吊顶内 | 排风管接至室外或公共烟道 | 湿气排不出去、发霉 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 防水层厚度 | ≥1.5mm，均匀无薄点 | 涂层测厚仪 |
| 地面坡度 | 向地漏1-2%，无倒坡 | 水平仪 |
| 地漏排水 | 倒水测试，排水通畅无积水 | 通水测试 |
| 墙地砖空鼓率 | 单块砖空鼓≤10%，整间≤5% | 空鼓锤 |
| 插座防溅盒 | 所有插座配有防溅盒 | 目测 |
| 排风效果 | 排风扇风量≥100m³/h，运转正常 | 风速仪/手感 |
| 闭水试验 | 24小时无渗漏 | 水位标记、目测 |

## 注意事项

- 卫生间面积小于4㎡时，建议用淋浴帘代替玻璃隔断，节省空间
- 智能马桶插座应预留在马桶侧后方，距地35-40cm，不要预留在马桶正后方
- 卫生间门槛石应高于室内地面5-10mm，并做防水翻边，防止水从门槛处渗出
- 暗卫（无外窗卫生间）必须安装大功率排风扇（≥150m³/h），有条件可安装新风
- 淋浴区地面建议做拉槽处理（防滑槽），提高防滑性能
- 卫生间排水建议使用75mm管径的主排水管，50mm支管，避免排水不畅
- 卫生间装修完成后至少通风2周再安装浴室柜等木质洁具，避免受潮变形
