# 装修防水规范

## 防水区域

| 区域 | 防水范围 |
|------|---------|
| 卫生间 | 地面全做，墙面≥1.8m |
| 厨房 | 地面全做，墙面≥0.3m |
| 阳台 | 地面全做，墙面≥0.3m |
| 地下室 | 墙面地面全做 |

## 施工要点

1. 基层处理干净
2. 管根加强处理
3. 阴阳角做圆弧
4. 涂刷2-3遍
5. 厚度≥1.5mm
6. 闭水试验24小时

## 验收标准

| 检查项 | 标准 |
|--------|------|
| 防水层厚度 | ≥1.5mm |
| 闭水试验 | 24小时无渗漏 |
| 防水高度 | 卫生间≥1.8m |

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第6.3节规定防水层粘结牢固、无渗漏
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第6.4节规定厨房、卫生间防水施工要求
- **JGJ/T 235-2011**《建筑外墙防水工程技术规程》：涉及阳台等外墙节点防水
- **JC/T 2415-2017**《聚合物水泥防水涂料》：材料性能指标要求

## 施工 SOP 流程

1. **基层处理**：清理基层至无浮灰、无油污，含水率≤9%，含水率检测可用塑料薄膜覆盖法
2. **细部附加层**：管根、地漏、阴阳角等部位先刷1.5mm厚附加层，宽度≥200mm
3. **第一遍涂刷**：横刷防水涂料，用量约0.6kg/m²，厚度均匀
4. **第二遍涂刷**：间隔4-8小时（以手触不粘为准），竖刷方向与第一遍垂直
5. **第三遍涂刷**：补充薄弱部位，总厚度≥1.5mm，用测厚仪检测
6. **养护**：施工后24小时内禁止踩踏，48小时后进行闭水试验
7. **闭水试验**：蓄水深度30-50mm，水位做标记，24小时后检查水位变化和楼下对应部位
8. **保护层施工**：闭水合格后做20mm厚1:3水泥砂浆保护层

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 防水只刷一遍 | 至少刷2-3遍，十字交叉涂刷 | 涂层有针孔，易渗漏 |
| 管根不做附加层 | 管根四周200mm范围做附加层 | 管根处最先渗漏 |
| 防水层上直接贴砖 | 先做水泥砂浆保护层再贴砖 | 贴砖时破坏防水层 |
| 闭水时间不足12小时 | 蓄水24小时以上 | 无法发现慢渗漏 |
| 门槛石处防水断开 | 防水延伸至门槛石下方300mm | 水从门槛石处渗出到客厅 |
| 基层潮湿直接刷防水 | 基层含水率≤9%再施工 | 防水层起鼓、脱落 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 防水层厚度 | ≥1.5mm，均匀无薄点 | 涂层测厚仪、针测法 |
| 防水高度 | 淋浴区≥1.8m，其他区域≥0.3m | 钢卷尺 |
| 粘结强度 | ≥0.5MPa | 拉拔仪 |
| 闭水试验 | 24小时水位无明显下降，楼下无渗漏 | 水位标记、目测 |
| 表面质量 | 无气泡、无裂纹、无起皮 | 目测、手触 |
| 细部处理 | 管根、地漏、阴阳角附加层完整 | 目测、手触 |

## 注意事项

- 防水涂料施工环境温度5-35°C，相对湿度≤85%，雨天不宜施工
- 聚氨酯防水涂料需注意：单组份开桶即用，双组份严格按比例调配并搅拌均匀
- JS防水涂料施工前需润湿基层但不得有明水
- 防水层完成后应尽快做保护层，避免长期暴露导致老化
- 闭水试验时如水位下降超过2mm，需排查原因并重新做防水
- 旧房翻新时原有防水层应彻底铲除后再重新施工
- 防水施工前应确认所有水管试压合格，避免返工
