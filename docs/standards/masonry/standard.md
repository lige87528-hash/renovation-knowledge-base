# 装修泥瓦施工规范

## 砌筑工程

### 基本要求
- 砂浆配合比符合设计
- 灰缝厚度8-12mm
- 每天砌筑高度≤1.8m

### 验收标准
| 项目 | 标准 |
|------|------|
| 垂直度 | ≤3mm/2m |
| 平整度 | ≤4mm/2m |
| 灰缝饱满度 | ≥80% |

## 防水工程

### 基本要求
- 厨卫地面全做防水
- 墙面淋浴区≥1.8m
- 闭水试验24小时

### 验收标准
| 项目 | 标准 |
|------|------|
| 防水层厚度 | ≥1.5mm |
| 闭水试验 | 24小时无渗漏 |

## 贴砖工程

### 基本要求
- 基层处理干净
- 砖缝均匀
- 空鼓率≤5%

### 验收标准
| 项目 | 标准 |
|------|------|
| 平整度 | ≤2mm/2m |
| 空鼓率 | ≤5% |
| 砖缝 | 均匀一致 |

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第7章抹灰工程、第8章镶贴工程
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第6章砌筑和防水工程要求
- **JGJ/T 220-2010**《抹灰砂浆技术规程》：抹灰砂浆配合比和施工要求
- **GB 50203-2011**《砌体结构工程施工质量验收规范》：砌筑工程质量验收

## 施工 SOP 流程

### 砌筑工程
1. **放线定位**：在地面和墙面弹出墙体位置线，确认垂直度和水平度
2. **基层处理**：清理基层，浇水润湿（混凝土基层涂刷界面剂）
3. **砌筑**：砂浆配合比符合设计要求，灰缝8-12mm，每天砌筑高度≤1.8m
4. **植筋**：新建墙体与原有墙体交接处植入拉结筋，间距≤500mm

### 防水工程
1. 基层处理→细部附加层→防水涂刷（2-3遍）→闭水试验→保护层

### 贴砖工程
1. **基层处理**：清理基层，涂刷界面剂
2. **弹线排砖**：地面弹出十字基准线，墙面弹出水平控制线
3. **预排**：干排确认砖缝位置和切割砖位置
4. **铺贴**：从中间向四周或从一角向另一角铺贴，用找平器控制砖缝
5. **勾缝/美缝**：铺贴完成24小时后勾缝或做美缝

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 砌筑砂浆太稀 | 砂浆稠度7-10cm | 灰缝变形、墙体不稳 |
| 新建墙体不植筋 | 交接处植入拉结筋，间距≤500mm | 新旧墙体连接处开裂 |
| 瓷砖泡水时间不够 | 泡水至不冒气泡（约2小时） | 空鼓、脱落 |
| 贴砖从门口开始 | 从中间或显眼位置开始 | 边角出现切割窄条 |
| 砖缝不均匀 | 使用找平器控制 | 不美观 |
| 防水层上直接贴砖 | 先做水泥砂浆保护层 | 贴砖破坏防水层 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 砌筑垂直度 | ≤3mm/2m | 2m靠尺、线坠 |
| 砌筑平整度 | ≤4mm/2m | 2m靠尺 |
| 灰缝饱满度 | ≥80% | 目测、手推 |
| 贴砖平整度 | ≤2mm/2m | 2m靠尺 |
| 贴砖空鼓率 | 单块≤10%，整间≤5% | 空鼓锤 |
| 砖缝宽度 | 均匀一致，偏差≤0.5mm | 塞尺 |
| 防水层厚度 | ≥1.5mm | 涂层测厚仪 |

## 注意事项

- 新建墙体顶部应斜砌挤紧（斜砖角度约60°），防止后期下沉开裂
- 轻质砖砌筑前应先浇水润湿，但不得有明水
- 瓷砖铺贴前应进行预排，避免出现小于1/3砖宽的窄条
- 地砖铺贴完成后48小时内禁止踩踏，养护期间保持湿润
- 美缝施工应在瓷砖铺贴完成至少7天后进行，确保缝隙干燥
- 大面积瓷砖铺贴应设置伸缩缝，防止热胀冷缩导致开裂
