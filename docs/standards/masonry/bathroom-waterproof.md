# 卫生间防水详解

## 防水材料选择

| 材料 | 特点 | 适用场景 | 价格（元/㎡） |
|------|------|---------|-------------|
| 聚氨酯防水涂料 | 弹性好、耐老化 | 卫生间地面墙面 | 30-50 |
| JS 防水涂料 | 环保、可厚涂 | 墙面 | 20-40 |
| 丙纶防水卷材 | 施工快 | 大面积 | 15-30 |

## 施工流程

1. **基层处理：** 清理基层、找平、阴阳角做圆弧处理
2. **细部加强：** 管根、门槛石等部位先做附加层
3. **涂刷防水：** 第 1 遍横刷 → 干燥 → 第 2 遍竖刷 → 干燥 → 第 3 遍补充，总厚度≥1.5mm
4. **闭水试验：** 蓄水 24 小时，到楼下检查无渗漏
5. **保护层：** 水泥砂浆保护层，后续贴砖

## 关键部位

### 管根处理
1. 管周围 200mm 加强
2. 涂刷厚度≥2mm
3. 套管与管道密封

### 门槛石防水
1. 门槛石下方先做防水
2. 防水翻边≥300mm
3. 两侧也做防水

## 验收标准

| 检查项 | 标准 |
|--------|------|
| 防水层厚度 | ≥1.5mm |
| 闭水试验 | 24小时无渗漏 |
| 防水高度 | 淋浴区≥1.8m |

## 施工 SOP 流程

1. **基层处理**：铲除原有松动层，清理浮灰油污，修补裂缝，含水率≤9%
2. **细部附加层**：管根、地漏、门槛石、阴阳角等部位先刷附加层，宽度≥200mm
3. **第一遍涂刷**：横刷防水涂料，厚度均匀约0.6mm
4. **第二遍涂刷**：间隔4-8小时（手触不粘为准），竖刷与第一遍交叉
5. **第三遍涂刷**：补充薄弱部位，总厚度≥1.5mm
6. **养护**：24小时内禁止踩踏，48小时后进行闭水试验
7. **闭水试验**：蓄水深度30-50mm，24小时水位无明显下降，到楼下检查
8. **保护层**：闭水合格后做20mm厚1:3水泥砂浆保护层，后续可贴砖

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 只刷一遍防水涂料 | 至少2-3遍，十字交叉涂刷 | 涂层有针孔渗漏 |
| 管根不做附加层 | 管根四周200mm附加层 | 管根最先渗漏 |
| 闭水试验时间不够 | 蓄水24小时以上 | 无法发现慢渗漏 |
| 门槛石处防水断开 | 防水延伸至门槛石下方300mm | 水渗到客厅 |
| 防水层上直接贴砖 | 先做水泥砂浆保护层 | 贴砖破坏防水层 |
| 涂料一次性涂刷过厚 | 分遍涂刷，每遍≤0.8mm | 涂层开裂 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 防水层厚度 | ≥1.5mm，均匀无薄点 | 涂层测厚仪 |
| 防水高度 | 淋浴区≥1.8m，其他≥0.3m | 钢卷尺 |
| 闭水试验 | 24小时水位无明显下降 | 水位标记 |
| 楼下检查 | 对应部位无渗漏、无水渍 | 目测 |
| 细部处理 | 管根、阴阳角附加层完整 | 目测、手触 |
| 表面质量 | 无气泡、裂纹、起皮 | 目测 |

## 注意事项

- 防水施工前必须确认所有水管试压合格，避免返工
- 卫生间墙面如果是轻质隔墙，建议全墙面做防水
- 防水涂料施工环境温度5-35°C，雨天不宜施工
- 闭水试验时如水位下降超过2mm，需排查原因并重新做防水
- 旧房翻新时原有防水层应彻底铲除后再重新施工
- 防水层完成后尽快做保护层，避免长期暴露老化
