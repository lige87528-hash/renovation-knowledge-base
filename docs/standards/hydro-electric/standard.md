# 装修水电改造规范

## 改造原则

- 走顶不走地
- 强弱电分离
- 横平竖直

## 电路改造

### 回路设计
| 回路 | 电线 | 空开 |
|------|------|------|
| 照明 | 1.5mm² | 16A |
| 插座 | 2.5mm² | 20A |
| 空调 | 4mm² | 25A |
| 厨房 | 4mm² | 25A |
| 卫生间 | 4mm² | 25A |

### 施工要点
- PVC线管敷设
- 强弱电间距≥30cm
- 电线穿管

## 水路改造

### 管材选择
- PPR管：热熔连接
- 冷热水管分开

### 施工要点
- 冷热水间距≥15cm
- 管卡固定
- 打压测试

## 验收要点

- 打压测试合格
- 电路通路正常
- 拍照记录管线走向

## 相关国家标准

- **GB 50242-2002**《建筑给水排水及采暖工程施工质量验收规范》：水路管道敷设、连接和试压
- **GB 50303-2015**《建筑电气工程施工质量验收规范》：电气管线敷设、接线和测试
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第4章水电气工程施工要求
- **JGJ 242-2011**《住宅建筑电气设计规范》：住宅电气回路配置和插座布置
- **GB 50015-2019**《建筑给水排水设计标准》：给水管材选择和管径计算

## 施工 SOP 流程

1. **图纸会审**：确认水路走向、回路分配、插座和开关位置，标注在墙面
2. **开槽**：墙面竖向开槽深度=管径+10mm，禁止承重墙横向开槽超过30cm
3. **水路布管**：PPR管热熔连接，冷热水管间距≥15cm，左热右冷
4. **电路布管**：PVC线管敷设，强弱电分分管，间距≥30cm
5. **穿线**：不同回路不穿同一根管，线管内电线截面积≤40%管截面积
6. **水路打压**：打压至0.8MPa，稳压30分钟，压降≤0.05MPa为合格
7. **电路测试**：兆欧表测试绝缘电阻≥0.5MΩ，万用表测试通路
8. **拍照存档**：管线走向拍照记录，标注尺寸，便于后期维修定位

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 水管热熔时间不足 | 按管径控制热熔时间（20管约5秒） | 接头渗漏 |
| 强弱电穿同一根管 | 强弱电分分管，间距≥30cm | 信号干扰 |
| 不做打压测试 | 打压0.8MPa稳压30分钟 | 埋下渗漏隐患 |
| 线管内电线塞满 | 电线截面积≤40%管截面积 | 散热不良、绝缘老化 |
| 电线接头在线管内 | 所有接头在底盒内 | 维修困难、短路起火 |
| 管线走向不记录 | 拍照存档标注尺寸 | 后期安装打孔破坏管线 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 水压测试 | 0.8MPa/30min，压降≤0.05MPa | 打压泵、压力表 |
| 绝缘电阻 | ≥0.5MΩ（500V兆欧表） | 兆欧表 |
| 强弱电间距 | ≥30cm | 钢卷尺 |
| 冷热水间距 | ≥15cm，左热右冷 | 钢卷尺 |
| 管线固定间距 | ≤80cm，转角处加密 | 钢卷尺 |
| 管线走向记录 | 拍照存档，标注尺寸 | 照片 |

## 注意事项

- 水路改造完成后打压测试必须做，不可用通水代替打压
- 电线必须使用国标铜芯线，禁止使用铝线
- 线管弯曲必须使用弯管器，禁止使用90度直接头
- 水电改造费用通常按实际米数计算，施工前应确认单价和预估总量
- 水电管线走向拍照存档非常重要，后期安装挂件、打孔时避免破坏
- 水路走顶便于发现渗漏和维修，但成本高于走地
- 强电箱应配置漏保总开关，各分回路配置单极或双极空开
