# 电路施工详解

## 回路设计

### 基本回路
| 回路 | 电线截面 | 空开规格 |
|------|---------|---------|
| 照明 | 1.5mm² | 16A |
| 插座 | 2.5mm² | 20A |
| 空调 | 4mm² | 25A |
| 厨房 | 4mm² | 25A |
| 卫生间 | 4mm² | 25A |
| 冰箱 | 2.5mm² | 16A |

## 施工工艺

### 开槽
- 深度：管径+10mm
- 宽度：管径+20mm
- 禁止横槽超过30cm

### 布管
- PVC线管直径16mm或20mm
- 弯曲半径≥6倍管径
- 固定间距≤80cm

### 穿线
- 不同回路不穿同一根管
- 线管内电线≤40%截面积
- 接头在底盒内

## 验收要点

- [ ] 强弱电间距≥30cm
- [ ] 绝缘电阻≥0.5MΩ
- [ ] 回路与设计一致
- [ ] 管线走向拍照记录

## 相关国家标准

- **GB 50303-2015**《建筑电气工程施工质量验收规范》：电气管线敷设、接线和测试要求
- **GB 50054-2011**《低压配电设计规范》：回路设计、导线选择和保护电器配置
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第4章电气工程施工要求
- **JGJ 242-2011**《住宅建筑电气设计规范》：住宅电气回路配置和插座布置要求

## 施工 SOP 流程

1. **技术交底**：根据电气施工图纸，确认回路分配、插座位置、开关高度
2. **弹线定位**：在地面和墙面弹出管线走向线，标注底盒位置
3. **开槽**：墙面开槽深度=管径+10mm，宽度=管径+20mm，承重墙禁止横向开槽超过30cm
4. **布管**：PVC线管固定，弯曲半径≥6倍管径，管卡间距≤80cm
5. **穿线**：不同回路不穿同一根管，线管内电线截面积≤40%管截面积
6. **底盒安装**：底盒固定牢固，同一房间内底盒高度偏差≤2mm
7. **绝缘测试**：使用兆欧表测试各回路绝缘电阻，≥0.5MΩ为合格
8. **拍照存档**：对管线走向拍照记录，标注尺寸，便于后期维修定位

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 强弱电穿同一根管 | 强弱电分分管，间距≥30cm | 信号干扰 |
| 线管内电线过多 | 电线截面积≤40%管截面积 | 散热不良、绝缘老化 |
| 接头不在底盒内 | 所有接头在底盒内，线管内无接头 | 后期维修困难、短路 |
| 承重墙横向开槽超过30cm | 横槽≤30cm，竖向开槽 | 削弱墙体承载力 |
| 电线接头只用绝缘胶布 | 使用接线端子或压线帽 | 接头松动、发热起火 |
| 不同回路共用零线 | 每个回路独立零线 | 漏保跳闸、安全隐患 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 强弱电间距 | ≥30cm，交叉处做屏蔽处理 | 钢卷尺 |
| 绝缘电阻 | ≥0.5MΩ（500V兆欧表） | 兆欧表 |
| 线管固定间距 | ≤80cm，转角处加密 | 钢卷尺 |
| 底盒高度偏差 | 同一房间≤2mm | 水平仪 |
| 电线规格 | 与回路设计一致 | 游标卡尺、目测 |
| 管线走向记录 | 拍照存档，标注尺寸 | 照片、尺寸标注 |
| 接地连续性 | 接地可靠，电阻≤4Ω | 接地电阻测试仪 |

## 注意事项

- 电线必须使用国标铜芯线，禁止使用铝线或非标线
- 线管转弯处应使用弯管器弯曲，禁止使用90度直接头
- 卫生间、厨房等潮湿区域的电线管必须走顶不走地
- 大功率电器（空调、电热水器、电磁炉）必须单独回路
- 电线穿线前应检查线管是否畅通，可用穿线钢丝预先穿入
- 底盒安装时应考虑后期面板安装空间，底盒与墙面平齐或略低1-2mm
- 管线走向拍照存档非常重要，后期安装挂件、打孔时避免破坏管线
