# 装修材料存储规范

## 存储环境

### 温度
| 材料 | 存储温度 |
|------|---------|
| 涂料 | 5-35°C |
| 胶水 | 5-30°C |
| 木材 | 常温 |
| 瓷砖 | 常温 |

### 湿度
| 材料 | 存储湿度 |
|------|---------|
| 木材 | ≤60% |
| 石膏板 | ≤70% |
| 涂料 | ≤85% |

## 存储方法

- 离地存放（垫木板）
- 分类存放
- 避免阳光直射
- 远离水源

## 安全管理

- 易燃材料单独存放
- 施工现场禁烟
- 配备灭火器

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第3.3节材料保管与防护
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第3.3节材料储存管理要求
- **GB 50016-2014（2018版）**《建筑设计防火规范》：施工现场防火间距和消防设施配置
- **JGJ 146-2013**《建设工程施工现场环境与卫生标准》：材料堆放和现场管理

## 施工 SOP 流程

1. **进场前规划存储区域**：根据施工平面图划分材料堆放区，远离作业面和通道
2. **搭建临时存储设施**：室内材料存放区需防潮垫板，室外存放需搭设防雨棚
3. **分类分区码放**：按材料种类、规格、使用顺序分区码放，张贴标识牌
4. **建立出入库台账**：材料进场登记、领用登记，做到账物相符
5. **日常巡检**：每日检查存储环境（温湿度）、材料状态（有无受潮、变形）
6. **定期盘点**：每周盘点一次，发现问题及时处理，淘汰过期材料

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 木材直接堆放在地面 | 垫木板离地≥10cm，保持通风 | 木材吸潮变形、发霉 |
| 涂料露天存放 | 存放在5-35°C室内，避免阳光直射 | 涂料冻裂或高温变质 |
| 不同品牌材料混放 | 按品牌、规格、批次分开码放 | 使用混乱、无法追溯 |
| 水泥存放无防潮措施 | 水泥架空存放，底部铺防潮膜 | 水泥受潮结块失效 |
| 电线与水管堆放在一起 | 电线、管材分类存放 | 管材破损污染电线 |
| 胶水与涂料混放 | 胶水单独存放，远离热源 | 胶水提前固化失效 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 木材含水率 | ≤12%（南方），≤10%（北方） | 含水率检测仪 |
| 涂料存储温度 | 5-35°C，未冻结 | 温度计 |
| 水泥保质期 | 出厂≤3个月，无结块 | 目测、手触 |
| 电线绝缘层 | 无龟裂、老化迹象 | 目测、弯折测试 |
| 瓷砖码放高度 | 堆码不超过1.5m，防倾倒 | 目测 |
| 防火器材 | 灭火器在有效期内，数量充足 | 检查压力表、有效期 |

## 注意事项

- 水泥存储期超过3个月强度下降约10%-15%，超过6个月强度下降约20%-30%，应复检后使用
- 木材进场后应在施工环境中放置2-3天进行含水率平衡，减少变形风险
- 防水涂料、胶水等化工产品需严格注意保质期，过期产品坚决不用
- 施工现场材料堆放不得堵塞消防通道和疏散出口
- 油漆、稀剂等易燃物品应设置专用防火柜，远离明火和高温
- 瓷砖堆码时需考虑地面承重能力，大面积堆放前应确认楼板荷载
- 材料标签朝外放置，便于识别和盘点
