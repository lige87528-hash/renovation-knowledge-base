# 装修材料进场验收

## 验收流程

### 第一步：核对清单
1. 对照合同材料清单
2. 核对品牌、型号、规格
3. 核对数量

### 第二步：外观检查
1. 包装是否完好
2. 有无破损、变形
3. 生产日期和保质期

### 第三步：质量抽检
1. 抽查部分材料
2. 必要时送检

### 第四步：签字确认
1. 验收合格后签字
2. 不合格要求退换

## 主要材料验收要点

| 材料 | 检查项 |
|------|--------|
| 瓷砖 | 规格、等级、色差 |
| 地板 | 环保等级、含水率 |
| 涂料 | 环保标识、批次 |
| 水管电线 | 3C认证、规格 |
| 防水材料 | 品牌、保质期 |

## 相关国家标准

- **GB 6566-2010**《建筑材料放射性核素限量》：瓷砖等建材放射性检测
- **GB 18580-2017**《室内装饰装修材料 人造板及其制品中甲醛释放限量》：甲醛释放量≤0.124mg/m³
- **GB 18582-2020**《建筑用墙面涂料中有害物质限量》：VOC、重金属限量指标
- **GB/T 18883-2022**《室内空气质量标准》：交付前室内空气质量检测依据
- **GB/T 50327-2001**《住宅装饰装修工程施工规范》：第3.2节材料进场验收要求

## 施工 SOP 流程

1. **材料进场前准备**：施工方提前24小时通知业主或监理，准备好合同材料清单
2. **核对清单**：逐项对照合同材料清单，确认品牌、型号、规格、数量一致
3. **外观检查**：检查包装完整性、生产日期、保质期、合格证、3C标志等
4. **质量抽检**：对关键材料（电线、水管、防水材料）进行现场抽检，必要时送第三方检测
5. **文件归档**：收集产品合格证、检测报告、保修卡等文件，拍照存档
6. **签字确认**：验收合格由业主或监理签字确认，不合格材料要求退换并记录
7. **分类存放**：合格材料按类别存放至指定区域，做好防潮、防晒保护

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 只看品牌不看型号 | 核对品牌+型号+规格+等级 | 可能用低端系列替代 |
| 不检查生产日期 | 检查生产日期和保质期 | 过期材料影响施工质量 |
| 只点大件不点辅材 | 主材辅材全部清点 | 辅材以次充好难发现 |
| 不索要合格证和检测报告 | 要求提供并拍照存档 | 后期维权无据可查 |
| 电线不查线芯截面 | 用游标卡尺测量线芯直径 | 非标线存在安全隐患 |
| 不检查环保等级标识 | 确认E0/E1环保等级 | 甲醛超标影响健康 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 电线线芯截面 | 与标称值一致，偏差≤1% | 游标卡尺 |
| 电线3C标志 | 必须有CCC认证标志 | 目测 |
| PPR管材壁厚 | 冷水管≥1.9mm，热水管≥2.8mm（20管） | 游标卡尺 |
| 瓷砖尺寸偏差 | 长宽偏差≤±0.5%，平整度≤0.5% | 钢卷尺、塞尺 |
| 涂料环保标识 | 十环认证、法国A+等 | 目测标识 |
| 人造板环保等级 | E0级≤0.050mg/m³，E1级≤0.124mg/m³ | 查看检测报告 |
| 防水涂料保质期 | 未过期，包装密封完好 | 目测生产日期 |

## 注意事项

- 材料进场验收必须由业主或委托监理在场，不可由施工方单方面签收
- 重要材料（电线、水管、防水材料）建议拍照留存，包括外包装和内芯
- 对有异议的材料可送第三方检测机构（如CMA资质实验室）检测
- 材料清单应在合同中详细列明品牌、型号、规格、数量，避免模糊描述
- 分批进场的材料每次都要重新验收，不可一次验收覆盖全部
- 进口材料应提供报关单、商检证明和中文说明书
