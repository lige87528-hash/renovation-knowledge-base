# 装修噪音控制

## 噪音标准

| 时间段 | 噪音限值 |
|--------|---------|
| 白天（6:00-22:00） | ≤70dB |
| 夜间（22:00-6:00） | ≤55dB |

## 噪音来源

| 工序 | 噪音等级 |
|------|---------|
| 拆墙 | 80-100dB |
| 电锤开槽 | 90-110dB |
| 切割瓷砖 | 80-90dB |
| 电锯 | 85-95dB |
| 打磨 | 70-85dB |

## 降噪措施

### 施工方
- 使用低噪音设备
- 高噪音工序集中白天
- 关闭门窗施工

### 业主
- 提前通知邻居
- 与物业沟通施工时间

## 法律规定

- 法定休息日禁止噪音施工
- 工作日12:00-14:00禁止
- 违规可向环保部门投诉

## 相关国家标准

- **GB 3096-2008**《声环境质量标准》：各类声环境功能区环境噪声限值
- **GB 12523-2011**《建筑施工场界环境噪声排放标准》：昼间≤70dB，夜间≤55dB
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第3.6节施工扰民控制
- **《环境噪声污染防治法》**：第47条规定装修活动噪声管理要求
- **《物业管理条例》**：物业有权制定装修施工时间管理规定

## 施工 SOP 流程

1. **开工前报备**：施工方向物业报备施工计划，确认允许施工的时间段
2. **邻里通知**：开工前3天书面通知上下左右邻居施工时间和工期
3. **噪音工序排程**：将高噪音工序（拆墙、开槽、切割）集中安排在允许时段
4. **降噪措施落实**：关闭门窗施工，使用低噪音设备，必要时在作业面加隔音棉
5. **分时段控制**：上午8:00-12:00安排高噪音工序，下午14:00-18:00安排中低噪音工序
6. **投诉响应**：接到邻居投诉立即停工，协商解决后恢复施工
7. **阶段验收**：噪音敏感工序完成后检查降噪效果，调整后续安排

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 周末进行拆墙施工 | 周末只做无噪音工序（油漆、测量） | 邻居投诉、物业处罚 |
| 全天开电锤开槽 | 集中在上午8:00-11:30 | 持续扰民、矛盾升级 |
| 开窗切割瓷砖 | 关闭门窗施工 | 噪音直接传播到室外 |
| 不通知邻居就开工 | 提前3天通知 | 邻居不满、投诉不断 |
| 使用老旧高噪音设备 | 使用新型低噪音设备 | 噪音超标 |
| 中午休息时间施工 | 12:00-14:00停工休息 | 违反法规、被投诉 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 昼间噪音 | ≤70dB（距施工场地1m处） | 分贝仪 |
| 夜间噪音 | ≤55dB（距施工场地1m处） | 分贝仪 |
| 施工时间合规 | 工作日8:00-12:00、14:00-18:00 | 检查施工记录 |
| 邻里通知 | 提前3天书面通知 | 检查通知记录 |
| 物业报备 | 开工前完成报备手续 | 检查物业记录 |
| 设备状态 | 低噪音设备运转正常 | 目测、检测 |

## 注意事项

- 各地物业管理规定的施工时间可能不同，开工前务必向物业确认
- 拆除和开槽阶段是噪音最大的时期（90-110dB），应提前告知邻居并尽量缩短工期
- 可在施工房间门缝处塞隔音棉，能有效降低10-15dB噪音
- 对于有婴儿、老人或居家办公的邻居，应特别协商施工时间
- 电锤、电镐等高噪音设备可考虑租用带隔音罩的新型设备
- 如确需加班赶工，应提前征得邻居和物业同意，并严格控制噪音
- 保留好邻居协商记录和物业报备凭证，作为纠纷处理依据
