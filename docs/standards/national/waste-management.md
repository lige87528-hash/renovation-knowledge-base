# 装修垃圾清运规范

## 垃圾分类

| 类型 | 内容 | 处理方式 |
|------|------|---------|
| 建筑垃圾 | 砖块、混凝土 | 专用车辆 |
| 可回收 | 纸箱、金属 | 回收利用 |
| 有害 | 涂料桶 | 专门处理 |

## 清运费参考

| 城市 | 费用（元/车） |
|------|-------------|
| 北京 | 500-800 |
| 上海 | 400-700 |
| 广州 | 300-600 |
| 成都 | 200-400 |

## 清运流程

1. 分类收集
2. 堆放指定位置
3. 清运车辆进场
4. 运到消纳场

## 注意事项

- 合同约定清运费由谁承担
- 不能堆放在公共区域
- 不能私自倾倒

## 相关国家标准

- **GB 50327-2001**《住宅装饰装修工程施工规范》：第3.5节施工现场垃圾管理
- **JGJ 146-2013**《建设工程施工现场环境与卫生标准》：垃圾分类、堆放和清运要求
- **CJJ 138-2010**《城镇建筑垃圾管理规定》：建筑垃圾处置、运输和消纳管理
- **GB 18599-2020**《一般工业固体废物贮存和填埋污染控制标准》：有害垃圾处理要求

## 施工 SOP 流程

1. **垃圾分类**：施工现场设置分类垃圾桶，分为建筑垃圾、可回收物、有害垃圾三类
2. **定点堆放**：在物业指定区域集中堆放，建筑垃圾堆放高度不超过1.5m
3. **及时清运**：每道工序完成后24小时内完成垃圾清理，不跨工序堆积
4. **联系清运车辆**：提前联系有资质的清运公司，确认消纳场和运输路线
5. **装车清运**：装车时洒水降尘，车辆覆盖篷布防止沿途遗撒
6. **消纳处置**：运至政府指定的建筑垃圾消纳场，取得处置凭证
7. **现场清理**：清运完成后清扫现场，恢复施工区域整洁

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 建筑垃圾混入生活垃圾 | 严格分类，建筑垃圾专用清运 | 物业拒收、罚款 |
| 垃圾堆放在楼道或电梯口 | 堆放在物业指定区域 | 影响居民通行、投诉 |
| 私自倾倒在路边 | 运至指定消纳场 | 违法、面临高额罚款 |
| 垃圾堆积不清运 | 每道工序后及时清运 | 施工空间受限、安全隐患 |
| 含水垃圾不密封运输 | 湿垃圾密封装袋运输 | 遗撒污染环境 |
| 涂料桶当普通垃圾处理 | 有害垃圾专门回收处理 | 污染土壤和水源 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 垃圾分类率 | 分类准确率≥90% | 目测抽检 |
| 现场整洁度 | 无垃圾堆积，通道畅通 | 目测 |
| 清运及时性 | 工序完成后24小时内清理 | 施工日志 |
| 清运凭证 | 取得消纳场处置凭证 | 检查单据 |
| 公共区域保护 | 楼道、电梯无垃圾污染 | 目测 |
| 有害垃圾处理 | 涂料桶、胶桶等专门回收 | 检查回收记录 |

## 注意事项

- 装修垃圾清运费用一般在500-1500元/套（视面积和城市而定），应在合同中明确承担方
- 部分城市实行装修垃圾申报制度，需向城管部门申报后方可清运
- 旧房翻新拆除的垃圾量通常较大（100㎡约产生3-5吨垃圾），应提前估算清运量
- 可利用的旧材料（旧门窗、旧洁具等）可联系二手回收商，减少清运量和费用
- 清运车辆必须有建筑垃圾运输资质，否则可能面临城管部门处罚
- 高层住宅垃圾清运应使用货梯，严禁从窗口或阳台抛掷垃圾
- 夜间清运需经物业和城管批准，避免扰民投诉
