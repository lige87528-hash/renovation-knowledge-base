# 装修施工队管理

## 人员配置

| 工种 | 人数 | 工期 |
|------|------|------|
| 拆改工 | 2-3 | 3-5天 |
| 水电工 | 2-3 | 7-15天 |
| 泥瓦工 | 2-3 | 10-20天 |
| 木工 | 2-3 | 7-15天 |
| 油漆工 | 2-3 | 10-15天 |
| 安装工 | 2-3 | 5-10天 |

## 管理要点

### 进度管理
- 制定施工进度表
- 定期检查进度
- 及时调整

### 质量管理
- 每道工序验收
- 发现问题及时整改
- 做好记录

### 安全管理
- 安全第一
- 配备防护用品
- 遵守操作规程

### 材料管理
- 材料进场验收
- 分类存放
- 避免浪费

## 相关国家标准

- **GB/T 50327-2001**《住宅装饰装修工程施工规范》：第4章施工组织与管理要求
- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：施工过程质量控制要求
- **JGJ/T 304-2013**《住宅室内装饰装修工程质量验收规范》：分项工程验收流程
- **建市〔2014〕118号**《建筑施工企业资质管理规定》：施工人员资质要求

## 施工 SOP 流程

1. **人员配置**：根据工程规模和工种需求，合理配置各工种人员数量
2. **进场交底**：项目经理对全体工人进行技术交底，明确施工工艺和质量标准
3. **进度计划**：制定施工进度计划表（甘特图），明确各工序起止时间和衔接关系
4. **每日站会**：每日开工前10分钟站会，安排当日工作、强调安全和质量要求
5. **过程巡检**：项目经理每半天巡检一次，检查施工质量、进度和安全
6. **工序交接**：前一道工序验收合格后方可进入下一道工序，做好交接记录
7. **竣工验收**：全部工序完成后组织业主验收，整理竣工资料

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 没有进度计划表 | 制定甘特图进度计划 | 工期拖延、工序混乱 |
| 工人无证上岗 | 特种工种持证上岗（电工、焊工） | 质量不达标、安全隐患 |
| 工序交接无验收 | 每道工序验收合格后再交接 | 问题积压到后期难整改 |
| 项目经理不在现场 | 关键工序项目经理必须在场 | 质量问题无人把关 |
| 不按图纸施工 | 严格按施工图和变更单施工 | 返工、纠纷 |
| 没有施工日志 | 每日填写施工日志 | 问题追溯无据可查 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 人员资质 | 特种工种持证上岗 | 检查证件 |
| 施工进度 | 按计划执行，偏差≤10% | 对比甘特图 |
| 工序交接记录 | 完整签字 | 检查记录表 |
| 施工日志 | 每日填写，内容完整 | 检查日志 |
| 安全交底记录 | 全员签字确认 | 检查记录表 |
| 质量整改记录 | 问题闭环管理 | 检查整改单 |

## 注意事项

- 项目经理应具备5年以上装修施工管理经验，持有建造师或施工员证书
- 各工种之间应做好衔接，水电工完成管线后泥瓦工方可进场
- 施工队应配备专职安全员，负责每日安全巡查和记录
- 业主应指定一名对接人，避免多人多头指挥造成混乱
- 变更必须书面确认，口头变更无效，变更涉及费用和工期的需重新约定
- 施工队管理应注重工人生活条件，良好的生活条件能提高施工质量
- 建议每周召开一次业主-施工方沟通会，通报进度和问题
