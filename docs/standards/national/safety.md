# 装修安全施工

## 安全注意事项

### 用电安全
- 临时用电使用漏保
- 电线不拖地
- 不使用破损电线

### 高空作业
- 2m以上作业系安全带
- 脚手架牢固

### 防火安全
- 施工现场禁烟
- 配备灭火器
- 易燃材料单独存放

### 防尘安全
- 施工佩戴口罩
- 做好成品保护

## 安全事故处理

### 常见安全事故
| 类型 | 处理方法 |
|------|---------|
| 触电 | 断电、急救 |
| 坠落 | 急救、送医 |
| 火灾 | 灭火、报警 |
| 切割伤 | 止血、送医 |

### 应急措施
- 拨打120急救
- 保护现场
- 通知保险公司

## 安全责任

- 施工方负责施工安全
- 业主不得违规指挥
- 购买施工人员意外险

## 相关国家标准

- **JGJ 46-2005**《施工现场临时用电安全技术规范》：三级配电两级保护
- **JGJ 80-2016**《建筑施工高处作业安全技术规范》：2m以上高处作业安全要求
- **GB 50016-2014（2018版）**《建筑设计防火规范》：施工现场防火要求
- **GB 50720-2011**《建设工程施工现场消防安全技术规范》：消防设施配置
- **GB/T 50327-2001**《住宅装饰装修工程施工规范》：第3.4节安全生产管理

## 施工 SOP 流程

1. **安全交底**：施工前对全体工人进行安全技术交底，签字确认
2. **防护设施设置**：楼梯口、电梯井、阳台边设置防护栏杆和警示标志
3. **临时用电布置**：三级配电两级保护，漏电保护器动作电流≤30mA
4. **消防器材配置**：每50m²至少1具4kg干粉灭火器，易燃区加倍配置
5. **每日安全巡检**：开工前检查用电、脚手架、高空防护，填写巡检记录
6. **动火审批**：电焊、切割等动火作业办理动火证，旁边配备灭火器
7. **事故应急**：发生安全事故立即启动应急预案，拨打120并保护现场

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 临时用电无漏保 | 每回路安装30mA漏电保护器 | 触电伤亡 |
| 动火作业无灭火器 | 动火点旁边配备灭火器 | 火灾失控 |
| 高空作业不系安全带 | 2m以上必须系安全带 | 坠落伤亡 |
| 楼梯口无防护栏杆 | 设置≥1.2m高防护栏杆 | 人员坠落 |
| 电线拖地无保护 | 电线架空或穿管保护 | 破损漏电 |
| 不戴安全帽进入现场 | 全员佩戴安全帽 | 头部受伤 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 漏电保护器 | 动作电流≤30mA，动作时间≤0.1s | 漏保测试仪 |
| 灭火器 | 压力正常，有效期内 | 目测 |
| 安全带 | 完好，系挂点高于作业人员 | 目测 |
| 防护栏杆 | 高度≥1.2m，牢固 | 手推检查 |
| 安全交底记录 | 全员签字，内容完整 | 检查记录 |
| 动火审批 | 有动火证，旁边有灭火器 | 检查证件 |

## 注意事项

- 业主应购买第三方责任险（通常200-500元），施工方应为工人购买工伤保险
- 施工现场动火作业必须有专人监护，作业完成后检查确认无余火方可离开
- 装修施工不得改变建筑承重结构和消防设施位置
- 高处作业使用的梯子应放在坚实地面上，梯子与地面夹角约75°
- 油漆、稀剂等易燃物品应设置专用防火柜，远离明火和高温
- 安全事故发生后应保护现场，立即报告相关部门，不得隐瞒
