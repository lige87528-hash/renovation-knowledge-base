# 装修成品保护规范

## 保护范围

| 成品 | 保护方法 |
|------|---------|
| 入户门 | 保护膜包裹 |
| 窗户 | 保护膜+纸板 |
| 地暖管 | 地面保护板 |
| 瓷砖 | 地面保护板 |
| 地板 | 保护膜+纸板 |
| 洁具 | 保护罩 |
| 橱柜 | 保护膜 |

## 各阶段保护

### 拆改阶段
- 入户门保护
- 窗户保护
- 下水管道封堵

### 水电阶段
- 已安装管线保护

### 泥瓦阶段
- 已贴瓷砖保护
- 地漏封堵

### 木作阶段
- 已完成瓷砖保护

### 油漆阶段
- 地面保护
- 门窗保护

### 安装阶段
- 已安装成品保护

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第3.3节成品保护要求
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第3.3节施工过程中的成品保护
- **JGJ/T 304-2013**《住宅室内装饰装修工程质量验收规范》：成品保护验收要求

## 施工 SOP 流程

1. **制定保护方案**：开工前根据施工流程和材料进场顺序，制定成品保护方案
2. **入户门保护**：用加厚珍珠棉保护膜全面包裹门扇、门框，用胶带固定
3. **窗户保护**：窗框贴保护膜，玻璃贴保护膜+纸板，窗台覆盖保护板
4. **下水管道封堵**：所有下水管口用专用盖帽或胶带封堵，防止建筑垃圾进入
5. **已贴瓷砖保护**：铺贴完成后24小时覆盖地面保护板（PVC+编织布）
6. **已安装洁具保护**：马桶、洗手台安装后用保护罩覆盖
7. **交叉保护**：后续工序施工时，对已完成区域再次检查保护状态

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 瓷砖贴完不保护 | 立即覆盖地面保护板 | 后续工序划伤瓷砖 |
| 下水管口不封堵 | 用专用盖帽封堵 | 建筑垃圾堵塞管道 |
| 入户门不包裹 | 加厚保护膜全面包裹 | 门扇磕碰划伤 |
| 保护膜用透明胶带固定 | 使用美纹纸胶带 | 胶带残留难以清理 |
| 保护板拆除过早 | 竣工前不拆除 | 安装阶段损坏成品 |
| 地暖管不做保护 | 地面覆盖保护板 | 后续施工破坏地暖管 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 入户门保护 | 门扇门框全覆盖，无破损 | 目测 |
| 窗户保护 | 窗框和玻璃有保护膜 | 目测 |
| 下水管道 | 管口封堵严密 | 目测、手试 |
| 瓷砖保护 | 地面保护板覆盖完整 | 目测 |
| 洁具保护 | 有保护罩覆盖 | 目测 |
| 地面保护 | 保护板接缝重叠≥5cm | 目测 |

## 注意事项

- 保护膜应选用加厚珍珠棉材质（≥3mm），普通塑料膜保护效果差
- 固定保护膜使用美纹纸胶带，禁止使用透明胶带（残留胶痕）
- 地面保护板接缝处应重叠5cm以上，用胶带密封
- 地暖管区域的保护板应加厚（≥5mm），并标注地暖管线走向
- 成品保护是贯穿整个施工过程的持续性工作，不是一次性工作
- 保护材料费用一般在500-1000元左右，不可为省钱而降低保护标准
- 竣工交付前统一拆除保护材料，做好开荒保洁
