# 装修施工安全规范

## 安全要求

### 用电安全
- 临时用电使用漏保
- 电线不拖地
- 不使用破损电线

### 高空作业
- 2m以上系安全带
- 脚手架牢固

### 防火安全
- 施工现场禁烟
- 配备灭火器
- 易燃材料单独存放

## 安全事故处理

| 类型 | 处理方法 |
|------|---------|
| 触电 | 断电、急救 |
| 坠落 | 急救、送医 |
| 火灾 | 灭火、报警 |

## 安全责任

- 施工方负责安全
- 购买意外险
- 做好安全交底

## 相关国家标准

- **JGJ 46-2005**《施工现场临时用电安全技术规范》：三级配电两级保护，一机一闸一漏一箱
- **JGJ 80-2016**《建筑施工高处作业安全技术规范》：2m以上高处作业必须系挂安全带
- **GB 50016-2014（2018版）**《建筑设计防火规范》：施工现场防火间距、灭火器材配置
- **GB 50720-2011**《建设工程施工现场消防安全技术规范》：消防设施配置和管理
- **GB/T 50327-2001**《住宅装饰装修工程施工规范》：第3.4节安全生产管理

## 施工 SOP 流程

1. **进场安全交底**：施工方对全体施工人员进行安全技术交底，签字确认
2. **设置安全警示**：在危险区域（楼梯口、电梯井、阳台边）设置警示标志
3. **临时用电布置**：按JGJ 46要求设置三级配电、两级保护，漏电保护器动作电流≤30mA
4. **配备消防器材**：每50m²至少配置1具4kg干粉灭火器，易燃区增加配置
5. **每日安全巡检**：施工前检查用电安全、脚手架稳定性、高空防护设施
6. **安全例会**：每周召开安全例会，通报隐患和整改情况
7. **事故应急预案**：制定触电、火灾、坠落等事故应急处置流程

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 多个电器共用一个插座 | 一机一闸一漏一箱 | 过载引发火灾 |
| 漏电保护器用空开替代 | 使用合格的30mA漏电保护器 | 触电时无法及时切断电源 |
| 高空作业不系安全带 | 2m以上必须系挂安全带 | 坠落伤亡事故 |
| 灭火器过期不换 | 定期检查压力表和有效期 | 火灾时无法有效灭火 |
| 电线穿越通道无保护 | 电线架空或穿管保护 | 电线被踩踏破损漏电 |
| 切割作业无防护面罩 | 佩戴防护面罩和护目镜 | 铁屑火花伤眼 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 漏电保护器 | 动作电流≤30mA，动作时间≤0.1s | 漏电保护器测试仪 |
| 灭火器 | 压力指针在绿色区域，有效期内 | 目测压力表 |
| 安全带 | 完好无损，系挂点高于作业人员 | 目测 |
| 脚手架 | 牢固稳定，有防护栏杆 | 手推检查 |
| 临时用电 | 三级配电两级保护，线径匹配 | 万用表、目测 |
| 安全交底记录 | 全员签字，内容完整 | 检查记录表 |

## 注意事项

- 临时用电必须由持证电工操作，非电工严禁私拉乱接
- 施工现场动火作业（电焊、切割）需办理动火证，旁边配备灭火器
- 高处作业平台下方应设置安全网或防护棚，防止坠物伤人
- 拆除作业应自上而下进行，严禁上下同时拆除
- 施工现场应保持通风良好，特别是油漆作业和防水施工期间
- 夜间施工必须有充足照明，危险区域设置红色警示灯
- 业主应购买第三方责任险，施工方应为工人购买工伤保险
