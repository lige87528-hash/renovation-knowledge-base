# 装修环保施工指南

## 环保施工要点

### 材料处理
- 减少切割浪费
- 合理利用边角料
- 分类存放

### 废弃物处理
- 垃圾分类
- 可回收物回收
- 有害垃圾专门处理

### 噪音控制
- 高噪音工序集中在白天
- 关闭门窗施工
- 使用低噪音设备

## 环保检测

| 阶段 | 检测内容 |
|------|---------|
| 材料进场 | 环保等级检查 |
| 施工中 | 现场环境监测 |
| 竣工后 | 室内空气质量检测 |

## 绿色施工

- 节能减排
- 水资源节约
- 资源循环利用

## 相关国家标准

- **GB/T 50378-2019**《绿色建筑评价标准》：室内环境、材料环保性能评价
- **GB 50325-2020**《民用建筑工程室内环境污染控制标准》：甲醛、苯、TVOC等污染物限量
- **GB/T 50327-2001**《住宅装饰装修工程施工规范》：第3.6节环境保护与文明施工
- **GB/T 18883-2022**《室内空气质量标准》：交付前空气质量检测指标
- **HJ 571-2010**《环境标志产品技术要求 人造板及其制品》：环保材料选择依据

## 施工 SOP 流程

1. **环保材料选型**：按GB 50325要求，选用E0/E1级人造板、十环认证涂料、无苯胶水
2. **材料进场检测**：检查环保等级标识、检测报告，必要时抽样送检
3. **绿色施工组织**：合理安排工序，减少交叉作业产生的污染
4. **施工过程控制**：切割作业洒水降尘，油漆作业密闭施工后通风
5. **废弃物回收利用**：边角料分类回收，可再利用材料二次利用
6. **竣工空气质量检测**：封闭门窗12小时后，委托CMA资质机构检测
7. **不合格治理**：如检测超标，采用通风、活性炭、光触媒等方法治理后复检

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 使用E2级人造板 | 使用E0/E1级板材（甲醛≤0.050/0.124mg/m³） | 甲醛超标危害健康 |
| 用107胶水（含甲醛） | 使用环保型界面剂（无甲醛） | 室内空气污染严重 |
| 涂料施工后立即入住 | 通风2-4周后检测达标再入住 | 有害物质超标 |
| 不同污染工序同时施工 | 错开油漆、胶水、切割工序 | 交叉污染、浓度叠加 |
| 施工期间门窗紧闭不通风 | 施工间歇开窗通风 | 有害物质积累 |
| 认为环保材料叠加无污染 | 控制材料使用总量 | 叠加效应仍可能超标 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 甲醛浓度 | ≤0.08mg/m³（GB/T 18883-2022） | CMA检测/便携式检测仪 |
| 苯浓度 | ≤0.03mg/m³ | CMA检测 |
| TVOC | ≤0.60mg/m³ | CMA检测 |
| 氨浓度 | ≤0.20mg/m³ | CMA检测 |
| 氡浓度 | ≤150Bq/m³ | 氡检测仪 |
| 材料环保标识 | 十环认证、法国A+、E0/E1级 | 目测标识、查报告 |

## 注意事项

- 环保材料叠加使用也可能导致室内污染物超标，应控制材料使用总量
- 甲醛释放周期长达3-15年，仅靠短期通风不能彻底解决，选材是关键
- 夏季高温时甲醛释放量是冬季的2-3倍，建议夏季入住前务必检测
- 活性炭除甲醛需定期更换（一般15-20天），饱和后反而释放甲醛
- 新风系统可有效降低室内污染物浓度，建议在装修时预留安装条件
- 孕妇、婴幼儿家庭建议选择纯实木、水性漆、无机涂料等最环保材料
- 装修完工后建议至少通风1-3个月，夏季可适当缩短，冬季需延长
