# 装修施工注意事项

## 通用注意事项

### 安全第一
- 施工现场禁烟
- 配备灭火器
- 用电安全

### 文明施工
- 遵守施工时间
- 做好成品保护
- 垃圾及时清运

## 各阶段注意事项

### 拆改阶段
- 不拆除承重结构
- 做好公共区域保护
- 通知邻居

### 水电阶段
- 管线走向拍照记录
- 打压测试必须做
- 电路通路必须测

### 泥瓦阶段
- 防水闭水试验
- 瓷砖空鼓检查
- 坡度检查

### 木作阶段
- 龙骨间距检查
- 石膏板接缝处理
- 五金安装质量

### 油漆阶段
- 基层处理到位
- 每遍干透再刷
- 灯光检查平整度

### 安装阶段
- 成品保护到位
- 安装顺序正确
- 功能测试完整

## 与施工方沟通

- 定期沟通进度
- 问题及时反馈
- 做好记录
- 按合同执行

## 相关国家标准

- **GB 50327-2001**《住宅装饰装修工程施工规范》：全过程施工管理要求
- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：各分项工程质量要点
- **GB 50325-2020**《民用建筑工程室内环境污染控制标准》：环保施工要求
- **JGJ/T 304-2013**《住宅室内装饰装修工程质量验收规范》：分阶段验收注意事项

## 施工 SOP 流程（注意事项落实）

1. **开工前**：确认施工图纸、材料清单、进度计划，做好安全技术交底
2. **拆改阶段**：确认不拆除承重结构，做好下水管道封堵，通知邻居
3. **水电阶段**：管线走向拍照存档，打压测试和绝缘测试必须做
4. **防水阶段**：闭水试验24小时必须到楼下检查
5. **泥瓦阶段**：瓷砖空鼓检查，坡度检查，砖缝均匀度检查
6. **木作阶段**：龙骨间距检查，石膏板接缝处理，五金安装质量
7. **油漆阶段**：基层处理到位，每遍干透再刷，灯光检查平整度
8. **安装阶段**：成品保护到位，安装顺序正确，功能测试完整
9. **竣工阶段**：空气质量检测，全部功能调试，资料归档

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 口头变更不记录 | 所有变更书面确认 | 费用纠纷无据可查 |
| 不检查材料就施工 | 材料进场验收合格再施工 | 以次充好 |
| 隐蔽工程不验收 | 隐蔽前必须验收 | 问题无法追溯 |
| 不按合同付款 | 按合同约定节点付款 | 资金风险 |
| 不保留施工照片 | 关键节点拍照存档 | 后期维修无依据 |
| 竣工验收走过场 | 逐项对照标准验收 | 遗留问题入住后暴露 |

## 验收要点详解

| 阶段 | 必查项目 | 注意事项 |
|------|---------|---------|
| 拆改 | 不破坏承重结构 | 有疑问先查原始结构图 |
| 水电 | 打压、绝缘、拍照 | 不可用通水代替打压 |
| 防水 | 闭水24小时到楼下检查 | 水位下降需排查原因 |
| 泥瓦 | 空鼓率、平整度、坡度 | 空鼓锤逐块检查 |
| 木作 | 牢固度、平整度、环保等级 | 检查板材检测报告 |
| 油漆 | 平整度、色差、流坠 | 灯光侧照检查 |
| 安装 | 功能正常、无渗漏 | 逐项测试 |
| 竣工 | 空气质量、全部功能 | 封闭12小时后检测 |

## 注意事项

- 装修合同应详细列明材料品牌、型号、规格、数量，避免模糊描述
- 付款应按施工进度节点支付，不要一次性支付全款
- 施工期间建议每周到现场检查1-2次，重点关注隐蔽工程
- 发现问题应立即提出并要求整改，不要等全部完工后再处理
- 保留好所有材料合格证、检测报告、验收记录和施工照片
- 与施工方沟通应理性客观，既不过度干预施工也不放任不管
- 竣工验收后应要求施工方提供质保卡（一般水电工程质保5年，其他2年）
