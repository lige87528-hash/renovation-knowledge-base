# 装修施工工艺流程图

## 完整施工流程

```
拆改工程
    ↓
水电工程 → 水电验收
    ↓
防水工程 → 闭水试验
    ↓
泥瓦工程 → 泥瓦验收
    ↓
木作工程 → 木作验收
    ↓
油漆工程 → 油漆验收
    ↓
安装工程 → 安装验收
    ↓
开荒保洁
    ↓
竣工验收
```

## 关键节点

| 节点 | 检查内容 |
|------|---------|
| 水电验收 | 打压测试、通路测试 |
| 闭水试验 | 24小时无渗漏 |
| 泥瓦验收 | 平整度、空鼓率 |
| 木作验收 | 牢固度、平整度 |
| 油漆验收 | 表面质量、颜色 |
| 竣工验收 | 全部功能正常 |

## 材料进场顺序

1. 窗户 → 拆改阶段
2. 瓷砖 → 泥瓦阶段前
3. 地板 → 油漆阶段后
4. 门 → 油漆阶段后
5. 橱柜 → 泥瓦阶段前
6. 卫浴 → 泥瓦阶段前
7. 家具 → 安装阶段后

## 相关国家标准

- **GB 50327-2001**《住宅装饰装修工程施工规范》：第4章施工工序和流程
- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：分阶段验收要求
- **JGJ/T 304-2013**《住宅室内装饰装修工程质量验收规范》：工序交接和验收流程

## 施工 SOP 流程（全流程详解）

1. **拆改工程**：拆除非承重结构→新建墙体→垃圾清运→中间验收
2. **水电工程**：开槽布管→穿线→水管热熔→打压测试→绝缘测试→水电验收→拍照存档
3. **防水工程**：基层处理→附加层→防水涂刷（2-3遍）→闭水试验→防水验收→保护层
4. **泥瓦工程**：地面找平→墙面贴砖→地面贴砖→美缝→泥瓦验收
5. **木作工程**：吊顶龙骨→石膏板→柜体→木作验收
6. **油漆工程**：基层处理→腻子→打磨→底漆→面漆→油漆验收
7. **安装工程**：门→地板→橱柜→洁具→灯具→开关面板→安装验收
8. **开荒保洁**：全面清洁→功能调试→空气质量检测→竣工验收

## 关键节点详解

| 节点 | 检查内容 | 合格标准 | 常用工具 |
|------|---------|---------|---------|
| 水电验收 | 打压测试 | 0.8MPa/30min，压降≤0.05MPa | 打压泵 |
| 水电验收 | 绝缘测试 | ≥0.5MΩ | 兆欧表 |
| 闭水试验 | 防水效果 | 24小时无渗漏 | 水位标记 |
| 泥瓦验收 | 平整度 | ≤2mm/2m | 2m靠尺 |
| 泥瓦验收 | 空鼓率 | 整间≤5% | 空鼓锤 |
| 木作验收 | 牢固度 | 稳固不晃动 | 手推检查 |
| 木作验收 | 平整度 | ≤3mm/2m | 2m靠尺 |
| 油漆验收 | 平整度 | ≤2mm/2m | 2m靠尺、灯光 |
| 竣工验收 | 空气质量 | 甲醛≤0.08mg/m³ | CMA检测 |

## 材料进场时间规划

| 材料 | 进场时间 | 注意事项 |
|------|---------|---------|
| 窗户 | 拆改阶段前 | 定制周期15-30天，需提前下单 |
| 橱柜 | 泥瓦阶段前15天 | 需量尺定制，周期30-45天 |
| 瓷砖 | 泥瓦阶段前3天 | 多备5%-10%损耗 |
| 卫浴洁具 | 泥瓦阶段前 | 确认尺寸，预留安装空间 |
| 门 | 油漆阶段前15天 | 定制周期30-45天 |
| 地板 | 油漆阶段完成后 | 施工环境温度湿度达标 |
| 家具 | 安装阶段后 | 环保等级达标 |
| 灯具 | 安装阶段前 | 确认安装方式和电线预留 |

## 注意事项

- 定制类材料（门、橱柜、衣柜等）需提前30-45天下单，避免等料停工
- 材料进场时间应与施工进度匹配，过早进场占用空间且易损坏
- 每个关键节点验收合格后方可进入下一道工序
- 管线走向拍照存档非常重要，后期安装打孔时避免破坏
- 建议业主在水电、防水、竣工验收三个节点亲自到场
- 装修全程建议建立微信群（业主+施工方+监理），便于沟通和问题处理
