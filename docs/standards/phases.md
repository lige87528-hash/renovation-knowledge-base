# 装修施工阶段详解

## 施工阶段划分

### 第一阶段：拆改（3-5天）
- 拆除非承重墙
- 新建墙体
- 垃圾清运

### 第二阶段：水电（7-15天）
- 水路改造
- 电路改造
- 打压测试
- 电路测试

### 第三阶段：泥瓦（10-20天）
- 防水施工
- 闭水试验
- 贴砖
- 地面找平

### 第四阶段：木作（7-15天）
- 吊顶
- 柜体
- 地板龙骨

### 第五阶段：油漆（10-15天）
- 墙面处理
- 腻子批刮
- 涂料涂刷

### 第六阶段：安装（5-10天）
- 门安装
- 地板安装
- 洁具安装
- 灯具安装

### 第七阶段：收尾（3-5天）
- 保洁
- 调试
- 验收

## 相关国家标准

- **GB 50327-2001**《住宅装饰装修工程施工规范》：施工工序和流程要求
- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：各分项工程验收标准
- **JGJ/T 304-2013**《住宅室内装饰装修工程质量验收规范》：分阶段验收要求
- **GB 50325-2020**《民用建筑工程室内环境污染控制标准》：竣工空气质量检测

## 施工 SOP 流程（全流程详解）

1. **拆改阶段**：按图纸拆除非承重墙、铲除原墙面、拆除旧门窗，清运垃圾
2. **水电阶段**：开槽布管→穿线→水管热熔连接→打压测试→绝缘测试→拍照存档
3. **防水阶段**：基层处理→细部附加层→防水涂刷（2-3遍）→闭水试验→保护层
4. **泥瓦阶段**：地面找平→墙面贴砖→地面贴砖→门槛石安装→美缝
5. **木作阶段**：吊顶龙骨→石膏板→柜体制作→地板龙骨（如需）
6. **油漆阶段**：基层处理→界面剂→腻子2-3遍→打磨→底漆→面漆2遍
7. **安装阶段**：门→地板→橱柜→洁具→灯具→开关面板→五金挂件
8. **收尾阶段**：开荒保洁→功能调试→空气质量检测→竣工验收

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 跳工序施工 | 严格按工序逐道施工 | 质量问题堆积 |
| 上道工序未验收就进入下道 | 每道工序验收合格签字后再进入下道 | 问题难以追溯 |
| 多工序交叉作业 | 合理安排工序衔接时间 | 互相污染、返工 |
| 材料不按进度进场 | 按施工进度提前1-2天进场 | 材料积压或停工待料 |
| 不做中间验收 | 水电、防水、泥瓦等阶段做中间验收 | 问题到后期才发现 |
| 收尾阶段不调试 | 逐项调试功能再验收 | 交付后问题频发 |

## 验收要点详解

| 阶段 | 验收节点 | 核心检查项 |
|------|---------|-----------|
| 拆改 | 拆改完成 | 不破坏承重结构，垃圾清运完毕 |
| 水电 | 隐蔽工程验收 | 打压测试、绝缘测试、管线走向拍照 |
| 防水 | 闭水试验 | 24小时无渗漏 |
| 泥瓦 | 泥瓦验收 | 平整度、空鼓率、坡度、砖缝 |
| 木作 | 木作验收 | 牢固度、平整度、接缝处理 |
| 油漆 | 油漆验收 | 平整度、表面质量、颜色均匀 |
| 安装 | 安装验收 | 各功能正常、无渗漏 |
| 竣工 | 竣工验收 | 空气质量检测、全部功能正常 |

## 注意事项

- 各阶段工期会因房屋面积、户型复杂度和施工队规模有所不同，文中为参考值
- 雨季施工泥瓦和油漆阶段工期需适当延长，保证每遍工序充分干燥
- 定制类材料（橱柜、门、衣柜）需提前30-45天下单，避免等料停工
- 竣工验收前应完成所有整改项目，不要带问题入住
- 建议业主在关键节点（水电、防水、竣工验收）亲自到场验收
- 完整保留施工照片和验收记录，作为质保和维权依据
