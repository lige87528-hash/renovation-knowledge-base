# 门窗安装规范

## 门安装

### 施工流程
1. 安装门框
2. 校正垂直度
3. 填充发泡胶
4. 安装门扇
5. 调试五金

### 关键指标
- 门框垂直度≤2mm/2m
- 门扇与地面间隙5-8mm
- 合页数量≥3个

## 窗户安装

### 断桥铝窗户
1. 检查洞口尺寸
2. 安装窗框
3. 校正水平垂直
4. 固定
5. 发泡胶填充
6. 打胶密封
7. 安装玻璃
8. 调试五金

### 关键指标
- 窗框垂直度≤2mm/2m
- 密封严密
- 开合顺畅
- 排水孔通畅

## 验收要点

- [ ] 门窗开合顺畅
- [ ] 密封严密
- [ ] 五金正常
- [ ] 玻璃无破损

## 施工 SOP 流程

1. **洞口检查**：检查门窗洞口尺寸是否与设计一致，洞口偏差≤5mm，否则需修补
2. **框体安装**：将门窗框放入洞口，用木楔临时固定
3. **校正**：用水平仪和线坠校正门框垂直度（≤2mm/2m）和水平度
4. **固定**：门框用膨胀螺栓固定，间距≤60cm；窗框用膨胀螺栓或固定片固定
5. **填充**：门框与墙体缝隙用发泡胶填充，窗框缝隙同样处理
6. **密封**：发泡胶固化后切割平整，内外侧打耐候硅酮胶密封
7. **门扇/玻璃安装**：安装门扇或玻璃，调试合页和锁具
8. **五金调试**：调试门锁、窗锁、执手等五金配件，确保开合顺畅

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 门框固定点太少 | 每边≥3个固定点，间距≤60cm | 门框松动变形 |
| 合页只装2个 | 门高≥2m装3个合页，≤2m装2个 | 门扇下沉 |
| 发泡胶溢出未切割 | 发泡胶固化后切割平整再打胶 | 密封不严、不美观 |
| 窗框不校正直接固定 | 先校正垂直度再固定 | 窗户关闭不严 |
| 玻璃压条不紧固 | 压条四角固定牢固 | 玻璃松动有异响 |
| 门扇与地面间隙过大 | 间隙5-8mm | 隔音差、进风 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 门框垂直度 | ≤2mm/2m | 线坠、2m靠尺 |
| 门扇与地面间隙 | 5-8mm | 钢尺 |
| 合页数量 | 门高≥2m用3个，≤2m用2个 | 目测 |
| 开合顺畅度 | 门扇/窗扇开合无卡顿 | 操作检查 |
| 密封性能 | 关窗后不透风、不透光 | 手试、目测 |
| 打胶质量 | 胶缝均匀、无断点、无气泡 | 目测 |
| 排水孔 | 窗框排水孔通畅 | 倒水测试 |

## 注意事项

- 门安装前应先确定开启方向（内开/外开、左开/右开），避免装反
- 卫生间门应选用防潮材质（铝镁合金、塑钢），不宜用实木门
- 入户门建议选择甲级防盗门，钢板厚度≥1mm
- 断桥铝窗户安装时，窗框与洞口缝隙应均匀，单侧缝隙≤3mm
- 门套线安装时应与墙面紧密贴合，缝隙用密封胶封闭
- 门安装后如出现门关不严的情况，通常是因为门框变形或合页安装不正，应调整合页
- 五金配件（门锁、执手、合页）建议选择304不锈钢材质，防锈耐用
