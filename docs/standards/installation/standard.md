# 装修安装工程规范

## 地板安装

### 基本要求
- 地面找平
- 防潮垫铺设
- 留伸缩缝

### 验收标准
| 项目 | 标准 |
|------|------|
| 平整度 | ≤3mm/2m |
| 空鼓 | 无 |
| 异响 | 无 |

## 门安装

### 基本要求
- 门框垂直
- 发泡胶填充
- 五金安装牢固

### 验收标准
| 项目 | 标准 |
|------|------|
| 垂直度 | ≤2mm/2m |
| 开合 | 顺畅 |
| 缝隙 | 均匀 |

## 洁具安装

### 基本要求
- 安装牢固
- 连接正确
- 密封严密

### 验收标准
| 项目 | 标准 |
|------|------|
| 牢固度 | 稳固 |
| 渗漏 | 无 |
| 排水 | 顺畅 |

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第5章门窗、第9章地面工程
- **GB 50242-2002**《建筑给水排水及采暖工程施工质量验收规范》：洁具安装验收
- **GB/T 15036-2018**《实木地板》：实木地板的尺寸偏差和安装要求
- **GB/T 20238-2018**《木质地板铺装、验收和使用规范》：木地板铺装验收标准

## 施工 SOP 流程

### 地板安装
1. **地面检查**：平整度≤3mm/2m，含水率≤当地平衡含水率
2. **防潮垫铺设**：搭接宽度≥20cm，墙角翻边5cm
3. **预排**：干排确认铺设方向和切割位置
4. **铺设**：从一角开始逐排铺设，榫槽紧密咬合
5. **留缝**：四周留伸缩缝8-12mm
6. **踢脚线**：与地板和墙面贴合紧密，缝隙均匀

### 门安装
1. **洞口检查**：尺寸偏差≤5mm
2. **门框安装**：校正垂直度≤2mm/2m
3. **填充固定**：发泡胶填充缝隙，膨胀螺栓固定
4. **门扇安装**：调试合页和锁具

### 洁具安装
1. **定位**：按设计图纸确定安装位置
2. **固定**：膨胀螺栓或专用胶粘固定
3. **连接**：给水管和排水管连接，确保密封
4. **调试**：通水测试无渗漏，排水通畅

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 地面不平直接铺地板 | 先找平再铺（自流平或砂浆） | 地板异响、松动 |
| 地板四周不留缝 | 四周留8-12mm伸缩缝 | 地板起鼓变形 |
| 门框固定点太少 | 每边≥3个固定点 | 门框松动 |
| 洁具安装不打胶密封 | 连接处打防霉硅酮胶 | 渗水 |
| 踢脚线不贴合墙面 | 与墙面紧密贴合 | 积灰、不美观 |
| 马桶不试水 | 通水测试排水和渗漏 | 使用后发现渗漏 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 地板平整度 | ≤3mm/2m | 2m靠尺 |
| 地板异响 | 行走无异响 | 行走检查 |
| 门框垂直度 | ≤2mm/2m | 线坠、靠尺 |
| 门扇开合 | 顺畅无卡顿 | 操作检查 |
| 洁具牢固度 | 稳固不晃动 | 手推检查 |
| 洁具渗漏 | 通水后无渗漏 | 通水测试 |
| 踢脚线贴合 | 与墙面贴合，缝隙≤1mm | 目测、塞尺 |

## 注意事项

- 地板安装应在油漆工程完成后进行，避免交叉污染
- 实木地板安装前应在地面放置24小时进行含水率平衡
- 强化地板铺装方向建议与房间长边平行，视觉效果更好
- 门安装后如出现门关不严，通常是门框变形或合页安装不正
- 马桶安装时法兰圈要对准排污口，打胶密封防止返臭
- 洁具安装完成后应做好成品保护，避免后续施工损坏
- 安装阶段是装修的最后一道工序，应特别注意成品保护
