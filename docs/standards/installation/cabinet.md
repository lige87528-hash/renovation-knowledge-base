# 橱柜安装规范

## 安装流程

1. **检查墙面地面** — 平整度检查
2. **安装地柜** — 调整水平
3. **安装吊柜** — 固定牢固
4. **安装台面** — 接缝处理
5. **安装五金** — 调试
6. **安装电器** — 嵌入式电器

## 关键指标

| 项目 | 标准 |
|------|------|
| 地柜水平 | ≤2mm |
| 吊柜牢固 | 不晃动 |
| 台面接缝 | ≤0.5mm |
| 门板缝隙 | 均匀一致 |

## 注意事项

- 安装前检查材料是否完好
- 吊柜固定在承重墙上
- 台面与墙面留缝
- 水槽开孔准确

## 验收要点

- [ ] 柜体牢固
- [ ] 台面平整
- [ ] 门板开合顺畅
- [ ] 五金正常
- [ ] 水槽不渗漏

- **GB/T 18883-2022**《室内空气质量标准》：橱柜甲醛释放量要求

## 施工 SOP 流程

1. **安装前检查**：确认墙面平整度（≤3mm/2m）、地面水平度，水电管线位置已预留
2. **弹线定位**：根据设计图纸在地面和墙面弹出橱柜安装位置线和水准线
3. **地柜安装**：先安装地柜底座（踢脚板），调整地柜水平，地柜之间用连接件固定
4. **台面安装**：台面与墙面留3-5mm缝隙，台面接缝用专用胶密封，打磨平整
5. **吊柜安装**：在承重墙位置用膨胀螺栓固定吊码，吊柜底部距地面150-160cm
6. **五金安装**：铰链、滑轨、拉手安装牢固，调试门板缝隙均匀一致
7. **电器嵌入**：嵌入式电器按尺寸开孔安装，预留散热空间
8. **收边收口**：台面与墙面缝隙打防霉硅酮胶，踢脚板安装牢固

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 吊柜固定在轻质隔墙上 | 吊柜必须固定在承重墙或加固墙体 | 吊柜坠落伤人 |
| 台面接缝不处理 | 台面接缝用专用胶密封并打磨 | 渗水发霉 |
| 地柜不调水平直接固定 | 用水平仪调整后再固定 | 台面倾斜、柜门不齐 |
| 水槽开孔过大 | 开孔比水槽尺寸大3-5mm | 水槽松动渗水 |
| 五金用普通自攻螺丝 | 使用专用铰链螺丝和膨胀螺栓 | 五金松动脱落 |
| 橱柜背板不密封 | 背板与墙面接触面涂刷防潮漆 | 背板受潮发霉 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 地柜水平度 | ≤2mm/2m | 水平仪、2m靠尺 |
| 吊柜牢固度 | 膨胀螺栓固定，不晃动 | 手推检查 |
| 门板缝隙 | 均匀一致，间隙1.5-2mm | 塞尺 |
| 台面平整度 | ≤2mm/2m，无翘曲 | 2m靠尺 |
| 台面接缝 | ≤0.5mm，平滑无明显痕迹 | 目测、手触 |
| 抽屉滑轨 | 推拉顺畅，无异响 | 操作检查 |
| 水槽密封 | 通水后无渗漏 | 通水测试 |
| 台面与墙面缝隙 | 3-5mm，打胶均匀美观 | 目测、钢尺 |

## 注意事项

- 定制橱柜前必须先完成墙面和地面施工，确保尺寸精准
- 吊柜安装前必须确认墙体类型，轻质隔墙需预先加固或使用专用吊挂件
- 台面石材（石英石、人造石）搬运时需两人配合，避免磕碰
- 橱柜安装顺序：先地柜后台面再吊柜，便于操作和调整
- 水槽下水管应设置存水弯，防止返臭
- 橱柜内部建议预留2-3个插座（小家电、净水器、垃圾处理器用）
- 安装完成后需检查所有五金配件是否正常，门板是否需要二次调整
