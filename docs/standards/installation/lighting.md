# 照明设计规范

## 照明类型

| 类型 | 用途 | 适用场景 |
|------|------|---------|
| 基础照明 | 整体照亮空间 | 吸顶灯、筒灯 |
| 重点照明 | 突出特定区域 | 射灯、台灯 |
| 装饰照明 | 营造氛围 | 灯带、壁灯 |

## 色温选择

| 色温 | 光色 | 适用空间 |
|------|------|---------|
| 2700-3000K | 暖白 | 卧室、餐厅 |
| 4000K | 自然白 | 客厅、书房 |
| 5000-6500K | 冷白 | 厨房、卫生间 |

## 照度标准

| 空间 | 建议照度（lux） |
|------|----------------|
| 客厅 | 100-150 |
| 卧室 | 75-100 |
| 书房 | 300-500 |
| 厨房 | 150-200 |
| 卫生间 | 100-150 |

## 各空间方案

### 客厅
- 主灯+射灯+灯带

### 卧室
- 吸顶灯+床头灯

### 厨房
- 集成吊顶灯+吊柜灯带

### 卫生间
- 集成吊顶灯+镜前灯

## 相关国家标准

- **GB 50034-2013**《建筑照明设计标准》：各空间照度、色温、显色指数要求
- **GB 50303-2015**《建筑电气工程施工质量验收规范》：灯具安装和接线要求
- **GB 7000.1-2015**《灯具 第1部分：一般要求与试验》：灯具安全性能
- **JGJ 242-2011**《住宅建筑电气设计规范》：住宅照明回路和灯具布置要求

## 施工 SOP 流程

1. **方案设计**：根据各空间功能和面积，确定照明类型（基础/重点/装饰）和灯具数量
2. **回路预留**：按照明方案预留电线回路，不同照明回路独立控制
3. **灯具选型**：按GB 50034要求选择照度、色温、显色指数（Ra≥80）合适的灯具
4. **定位安装**：按设计图纸在天花板和墙面标注灯具位置，预留安装孔位
5. **接线安装**：灯具固定牢固，接线正确，接地可靠
6. **调试**：逐一测试灯具开关、调光功能，检查光照效果
7. **效果优化**：根据实际照明效果调整灯具位置或更换灯具

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 一个房间只有一个吸顶灯 | 基础照明+重点照明组合 | 照明死角、光线单调 |
| 全屋统一色温 | 不同空间用不同色温 | 空间氛围不佳 |
| 灯具功率过大 | 按空间面积计算所需功率 | 光线刺眼、浪费电 |
| 射灯直射墙面 | 射灯调整角度照射目标区域 | 光斑不均匀 |
| 卫生间用非防潮灯具 | 卫生间使用IP44以上防潮灯具 | 灯具受潮短路 |
| 灯带不配变压器 | LED灯带配专用变压器 | 灯带闪烁、寿命缩短 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 照度 | 客厅100-150lux，书房300-500lux | 照度计 |
| 色温一致性 | 同一空间色温偏差≤200K | 色温仪 |
| 显色指数 | Ra≥80 | 查看产品参数 |
| 灯具牢固度 | 安装牢固不晃动 | 手试 |
| 开关控制 | 开关控制回路正确 | 操作检查 |
| 卫生间防潮 | IP等级≥IP44 | 查看产品标识 |

## 注意事项

- 客厅建议采用"主灯+射灯+灯带"的组合方式，满足不同场景需求
- 书房照明建议色温4000K、照度300-500lux，有利于保护视力
- 厨房除集成吊顶灯外，吊柜下方建议加装灯带补充操作台照明
- 卧室照明宜柔和，避免眩光，床头两侧可各设一盏壁灯
- LED灯具应选择正规品牌，避免频闪和光衰过快
- 灯带安装时应预留散热空间，避免贴在不散热材质表面
- 智能照明系统可在装修时预留零线，便于后期升级
