# 装修施工常见问题

## 拆改问题

| 问题 | 原因 | 处理方法 |
|------|------|---------|
| 拆除承重墙 | 误判 | 停工、加固 |
| 垃圾未清运 | 遗漏 | 及时清运 |

## 水电问题

| 问题 | 原因 | 处理方法 |
|------|------|---------|
| 水管渗漏 | 接头不合格 | 重新连接 |
| 电路短路 | 接线错误 | 重新接线 |
| 水压不足 | 管径过小 | 更换管径 |

## 泥瓦问题

| 问题 | 原因 | 处理方法 |
|------|------|---------|
| 瓷砖空鼓 | 粘结不牢 | 拆除重铺 |
| 防水渗漏 | 厚度不够 | 重做防水 |
| 地面不平 | 找平不到位 | 重新找平 |

## 木作问题

| 问题 | 原因 | 处理方法 |
|------|------|---------|
| 吊顶开裂 | 石膏板接缝未处理 | 修补 |
| 柜体不稳 | 固定不牢 | 重新固定 |

## 油漆问题

| 问题 | 原因 | 处理方法 |
|------|------|---------|
| 墙面开裂 | 基层未处理 | 修补 |
| 涂料流坠 | 涂刷过厚 | 打磨重刷 |

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：各分项工程质量通病防治
- **GB 50327-2001**《住宅装饰装修工程施工规范》：施工质量通病预防要求
- **JGJ/T 304-2013**《住宅室内装饰装修工程质量验收规范》：质量缺陷判定标准

## 施工 SOP 流程（问题预防与处理）

1. **施工前交底**：明确各工序质量通病及预防措施，写入技术交底记录
2. **过程巡检**：项目经理每半天巡检，发现问题立即整改，不留到下一道工序
3. **工序验收**：每道工序完成后对照验收标准逐项检查，合格后签字
4. **问题记录**：发现质量问题拍照记录，分析原因，制定整改方案
5. **整改闭环**：整改完成后重新验收，确保问题彻底解决
6. **经验总结**：竣工后总结常见问题，形成企业质量通病防治手册

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 瓷砖空鼓不处理就美缝 | 空鼓砖拆除重铺后再美缝 | 空鼓砖脱落连带美缝开裂 |
| 墙面腻子层开裂不处理就刷漆 | 铲除开裂腻子层重新批刮 | 漆膜开裂影响美观 |
| 吊顶石膏板接缝不处理 | 接缝V型槽+嵌缝石膏+防裂网 | 后期接缝开裂 |
| 水管渗漏不排查直接补 | 排查全部接头，逐一排查 | 问题重复出现 |
| 地面不平直接铺地板 | 先做自流平找平再铺地板 | 地板异响、松动 |
| 防水层被破坏不修复就贴砖 | 修补防水层并重新做闭水试验 | 渗漏到楼下 |

## 验收要点详解

| 问题类型 | 检查方法 | 判定标准 |
|---------|---------|---------|
| 瓷砖空鼓 | 空鼓锤逐块敲击 | 单块空鼓≤10%，整间≤5% |
| 墙面平整度 | 2m靠尺检查 | 偏差≤2mm/2m |
| 吊顶裂缝 | 灯光照射观察 | 无可见裂缝 |
| 水管渗漏 | 打压测试（0.8MPa/30min） | 压降≤0.05MPa |
| 电路故障 | 兆欧表+相位检测仪 | 绝缘≥0.5MΩ，相位正确 |
| 防水渗漏 | 闭水试验24小时 | 无渗漏 |

## 注意事项

- 质量问题的根源多在基层处理不到位，应重点把控基层施工质量
- 隐蔽工程（水电、防水）的问题后期维修成本极高，施工时必须严格把关
- 瓷砖空鼓率是业主最容易自行检测的项目，建议在泥瓦验收时重点检查
- 墙面漆膜开裂多数原因是基层腻子处理不当，而非涂料本身问题
- 吊顶开裂多发生在石膏板接缝处和转角处，应做V型槽和防裂网处理
- 发现质量问题应立即整改，不要等全部完工后再集中处理
- 保留好施工照片和验收记录，作为后期维权和质保的依据
