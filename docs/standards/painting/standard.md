# 装修油漆施工规范

## 墙面工程

### 基本要求
- 基层处理干净
- 腻子批刮平整
- 涂料涂刷均匀

### 验收标准
| 项目 | 标准 |
|------|------|
| 平整度 | ≤2mm/2m |
| 表面质量 | 无流坠、透底 |
| 颜色 | 均匀无色差 |

## 木器漆工程

### 基本要求
- 基层处理干净
- 底漆封闭
- 面漆均匀

### 验收标准
| 项目 | 标准 |
|------|------|
| 表面 | 光滑均匀 |
| 颜色 | 一致 |
| 木纹 | 清晰（开放型） |

## 施工条件

- 温度：5-35°C
- 湿度：≤85%
- 通风良好

## 相关国家标准

- **GB 50210-2018**《建筑装饰装修工程质量验收标准》：第10章涂饰工程验收要求
- **GB 50327-2001**《住宅装饰装修工程施工规范》：第8章涂饰工程施工要求
- **GB 18582-2020**《建筑用墙面涂料中有害物质限量》：VOC、甲醛、重金属限量
- **GB/T 9756-2018**《合成树脂乳液内墙涂料》：内墙乳胶漆的技术性能指标
- **JGJ/T 29-2015**《建筑涂饰工程施工及验收规程》：涂饰施工工艺和验收标准

## 施工 SOP 流程

1. **基层处理**：清除墙面浮灰、油污，修补空鼓和裂缝，基层含水率≤10%
2. **界面剂涂刷**：涂刷界面剂（墙固）一遍，增强基层与腻子的粘结力
3. **第一遍腻子**：使用耐水腻子（JG/T 298-2010 Y型），批刮厚度1-2mm
4. **第二遍腻子**：间隔24小时（前一遍完全干透），批刮厚度1-2mm，找平
5. **打磨**：腻子干透后用240-360目砂纸打磨，灯光照射检查平整度
6. **底漆涂刷**：涂刷抗碱底漆一遍，封闭基层，提高面漆附着力
7. **第一遍面漆**：底漆干透后涂刷面漆，滚涂或喷涂，厚度均匀
8. **第二遍面漆**：间隔4-6小时，第二遍面漆涂刷方向与第一遍垂直

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 基层未干就批腻子 | 基层含水率≤10%再施工 | 腻子空鼓、起皮 |
| 腻子一次批刮太厚 | 每遍批刮1-2mm，多遍批刮 | 腻子开裂、脱落 |
| 不用底漆直接刷面漆 | 先刷抗碱底漆再刷面漆 | 面漆附着力差、发花 |
| 每遍间隔时间不足 | 前一遍完全干透再刷下一遍 | 漆膜起泡、流坠 |
| 打磨不平整就刷漆 | 灯光照射下打磨至无砂痕 | 墙面不平整、有砂痕 |
| 潮湿天气施工 | 湿度≤85%再施工 | 漆膜发白、不干 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 平整度 | ≤2mm/2m | 2m靠尺、塞尺 |
| 表面质量 | 无流坠、透底、起皮、刷痕 | 灯光照射、目测 |
| 颜色均匀性 | 无色差、发花 | 目测 |
| 阴阳角 | 顺直，偏差≤2mm | 阴阳角尺 |
| 漆膜附着力 | 划格法≤1级 | 划格器 |
| 腻子层 | 使用耐水腻子（Y型） | 查看材料标识 |

## 注意事项

- 耐水腻子（Y型）与普通腻子（N型）不可混用，耐水腻子施工后不可再用普通腻子修补
- 面漆涂刷前应搅拌均匀，稀释比例严格按产品说明（通常5%-10%）
- 深色面漆建议多刷一遍（3遍），避免透底
- 乳胶漆施工温度5-35°C，低于5°C漆膜无法正常成膜
- 打磨后必须清理墙面浮灰再刷底漆，否则影响漆膜附着力
- 不同批次的同一色号涂料可能存在色差，应一次性采购到位
- 油漆工程完成后应关门窗养护2-3天，让漆膜完全固化
