# 装修施工规范总览

## 国家标准

### GB/T 50327-2001 住宅装饰装修工程施工规范

涵盖了住宅装饰装修的全部施工要求。

### GB 50210 建筑装饰装修工程质量验收规范

规定了装饰装修工程质量验收标准。

## 施工规范分类

| 分类 | 内容 |
|------|------|
| 拆改 | 承重结构、拆除范围 |
| 水电 | 管线走向、材料规格 |
| 泥瓦 | 砌筑、防水、贴砖 |
| 木作 | 吊顶、柜体 |
| 油漆 | 墙面处理、涂料施工 |
| 安装 | 门、地板、洁具 |

## 施工要点

### 通用要求
- 横平竖直
- 牢固可靠
- 符合规范

### 质量要求
- 平整度达标
- 无空鼓开裂
- 无渗漏

### 安全要求
- 用电安全
- 高空作业安全
- 防火安全

## 施工 SOP 流程（全流程框架）

1. **施工准备**：图纸会审、材料采购、技术交底、保护方案制定
2. **拆改施工**：按图纸拆除非承重结构，清运垃圾，新建墙体
3. **水电施工**：按图纸开槽布管、穿线，完成打压测试和绝缘测试
4. **防水施工**：厨卫阳台防水，管根附加层，闭水试验
5. **泥瓦施工**：地面找平、墙面和地面贴砖、门槛石安装
6. **木作施工**：吊顶龙骨及石膏板安装、柜体制作
7. **油漆施工**：基层处理、腻子批刮、底漆面漆涂刷
8. **安装施工**：门、地板、洁具、灯具、开关面板安装
9. **竣工验收**：分项验收、空气质量检测、资料归档

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 不按图纸施工 | 严格按施工图和变更单施工 | 返工、纠纷 |
| 跳工序施工 | 按流程逐道工序，上道验收合格再进入下道 | 质量问题堆积 |
| 材料以次充好 | 按合同材料清单验收进场材料 | 质量不达标 |
| 隐蔽工程不验收 | 隐蔽前必须验收并拍照存档 | 后期维修困难 |
| 竣工验收走过场 | 逐项对照验收标准检查 | 遗留问题入住后暴露 |
| 不重视环保施工 | 使用环保材料，控制材料总量 | 室内空气污染 |

## 验收要点详解

| 验收阶段 | 核心检查项 | 关键工具 |
|---------|-----------|---------|
| 水电验收 | 打压测试、绝缘测试、管线走向 | 打压泵、兆欧表 |
| 防水验收 | 闭水试验24小时 | 水位标记 |
| 泥瓦验收 | 平整度、空鼓率、坡度 | 2m靠尺、空鼓锤、水平仪 |
| 木作验收 | 牢固度、平整度、接缝处理 | 水平仪、靠尺 |
| 油漆验收 | 平整度、表面质量、颜色 | 2m靠尺、灯光 |
| 竣工验收 | 全部功能正常、空气质量 | CMA检测 |

## 注意事项

- 装修施工应遵循"先隐蔽、后表面；先湿作业、后干作业；先粗活、后细活"的原则
- 每个施工阶段都应进行中间验收，不要等到全部完工才验收
- 合同应明确各阶段验收标准和不合格处理方式
- 建议聘请第三方监理进行专业验收，比自己验收更客观准确
- 所有验收结果应书面记录并签字确认，作为质保依据
- 装修质量七分靠施工、三分靠材料，施工过程的把控比材料选择更重要
