# 装修木工施工规范

## 吊顶工程

### 基本要求
- 主龙骨间距≤100cm
- 副龙骨间距≤40cm
- 吊杆间距≤100cm

### 验收标准
| 项目 | 标准 |
|------|------|
| 平整度 | ≤3mm/2m |
| 水平度 | ≤3mm/2m |
| 接缝处理 | 错开、嵌缝 |

## 柜体工程

### 基本要求
- 板材环保等级达标
- 封边严密
- 五金安装牢固

### 验收标准
| 项目 | 标准 |
|------|------|
| 牢固度 | 稳固不晃动 |
| 门板 | 开合顺畅 |
| 缝隙 | 均匀一致 |

## 地板工程

### 基本要求
- 地面找平
- 防潮垫铺设
- 留伸缩缝

### 验收标准
| 项目 | 标准 |
|------|------|
| 平整度 | ≤3mm/2m |
| 空鼓 | 无 |
| 异响 | 无 |

## 施工 SOP 流程

### 吊顶工程
1. **弹线定位**：在墙面弹出吊顶标高线，在顶面弹出龙骨位置线
2. **安装吊杆**：膨胀螺栓固定吊杆，间距≤100cm，吊杆直径≥φ6
3. **安装主龙骨**：主龙骨间距≤100cm，调平后固定
4. **安装副龙骨**：副龙骨间距≤40cm，与主龙骨十字交叉固定
5. **安装石膏板**：自攻螺丝固定，间距15-17cm，钉头沉入板面0.5-1mm
6. **接缝处理**：石膏板接缝V型槽，嵌缝石膏+防裂网处理
7. **防锈处理**：自攻螺丝点涂防锈漆

### 柜体工程
1. **测量放线**：按设计图纸测量放线
2. **框架制作**：按尺寸裁板组装
3. **封边**：封边条封边，接缝严密
4. **五金安装**：铰链、滑轨安装牢固
5. **调试**：调整门板缝隙均匀

### 地板工程
1. **地面找平**：平整度≤3mm/2m
2. **防潮垫铺设**：搭接宽度≥20cm
3. **地板铺设**：从一角开始，留伸缩缝8-12mm
4. **踢脚线安装**：与地板和墙面贴合紧密

## 常见错误对照表

| 错误做法 | 正确做法 | 后果 |
|---------|---------|------|
| 主龙骨间距过大 | 主龙骨间距≤100cm | 吊顶下沉变形 |
| 石膏板接缝不处理 | V型槽+嵌缝石膏+防裂网 | 后期接缝开裂 |
| 自攻螺丝间距过大 | 间距15-17cm | 石膏板固定不牢 |
| 地板不留伸缩缝 | 四周留8-12mm伸缩缝 | 地板起鼓变形 |
| 柜体板材甲醛超标 | 使用E0/E1级板材 | 室内空气污染 |
| 吊顶转角处直缝 | 转角处整板切割（L型） | 转角处开裂 |

## 验收要点详解

| 检查项 | 验收标准 | 检查工具 |
|--------|---------|---------|
| 吊顶平整度 | ≤3mm/2m | 2m靠尺 |
| 吊顶水平度 | ≤3mm/2m | 水平仪 |
| 龙骨间距 | 主龙骨≤100cm，副龙骨≤40cm | 钢卷尺 |
| 石膏板接缝 | V型槽+防裂网处理 | 目测 |
| 柜体牢固度 | 稳固不晃动 | 手推检查 |
| 地板平整度 | ≤3mm/2m | 2m靠尺 |
| 板材环保等级 | E0级≤0.050mg/m³ | 查看检测报告 |

## 注意事项

- 吊顶石膏板应使用9.5mm及以上厚度，厨房卫生间使用耐水石膏板
- 吊顶转角处石膏板必须用整板切割成L型，禁止在转角处拼接
- 定制柜体建议在生产前确认设计图纸和尺寸，避免尺寸误差
- 地板铺设前应在地面放置24小时进行含水率平衡，减少变形
- 吊顶内如有管线，应在封板前完成管线施工和验收
- 木作工程使用的自攻螺丝应做防锈处理，避免后期锈迹渗出
