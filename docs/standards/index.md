# 施工规范

住宅装饰装修工程施工规范是保障装修质量和居住安全的核心依据。本板块系统梳理了从国家标准到地方配套标准、从各工种专项施工规范到环保安全管理的完整标准体系，为业主监督施工质量和从业者规范操作提供权威参考。

**涵盖范围**：
- **国家标准**：GB50210（建筑装饰装修工程质量验收）、GB50327（住宅装饰装修工程施工）、GB50325（室内环境污染控制）、GB50222（建筑内部装修设计防火）等 6 项核心国标
- **行业标准**：中国建筑装饰协会发布的 130+ 项行业标准和团体标准
- **工种专项**：水电改造、泥瓦砌筑、木作吊顶、油漆涂装、设备安装五大工种的详细施工标准与验收要点
- **专项管理**：拆改工程、质量管理、安全施工、噪音控制、垃圾处理、成品保护、无障碍设计等 12 个专项管理规范

**使用建议**：
业主可在各施工阶段对照相应规范条款进行验收；从业者可将本板块作为日常施工的参考手册，确保工艺符合国家及行业标准。本板块所有标准均引用现行有效版本，并随国家标准更新同步修订。

> 📌 数据来源：住房和城乡建设部《住宅室内装饰装修管理办法》、中国建筑装饰协会行业标准汇编（2025版）
